# aiTrade

토스증권·한국투자증권(KIS) API와 AI를 활용하는 개인용 주식 투자·자동매매 프로젝트입니다.

## 목표

- 작은 기능부터 만들고, 실제 필요와 측정된 문제에 따라 기능과 구조를 개선합니다.
- 기능별 문제·해결 방법·개선 전후 수치·최종 결과를 기록합니다.
- 초기에는 개인 환경에서 운영합니다.

## 실행 환경과 증권사 역할

- 노트북에서 Docker로 실행하고 집 Wi-Fi에 연결된 PC·휴대폰에서 사용합니다.
- 개인 사용자 1명이 간단한 로그인으로 사용합니다.
- **토스증권:** 시세·계좌 정보 조회와 실제 주식 주문
- **KIS:** 토스에서 부족한 정보 조회. 실전 계좌를 사용하지만 주문하지 않음

현재는 **요구사항 문서화 단계**이며 구현 코드와 실행 설정은 없습니다.

## 단계별 범위

| 단계 | 핵심 기능 |
|---|---|
| 1차 | 국내 주식·국내 ETF·미국 주식 검색과 관심종목 관리, 실시간 시세·장 상태 확인 |
| 2차 | 보유종목·주문·거래내역 조회, 토스증권 지정가 수동매매, 주문·체결 알림 |
| 3차 | 국내 주식·국내 ETF AI 자동매매, 개인·전체·AI별 투자 현황과 성과 관리 |

## 핵심 원칙

- 실제 주문은 토스 실계좌 하나를 사용하고, 앱 장부에서 개인과 각 AI의 현금·보유·주문·거래·성과를 구분합니다.
- AI는 관심종목에 한정하지 않고 투자 범위 안에서 종목을 직접 탐색합니다.
- 여러 AI 투자자를 지원하되, 초기에는 중기 투자자 1명과 전략 1개로 시작합니다.
- 캐시·Redis·메시지큐 등의 구조는 실제 필요가 확인된 뒤 도입합니다.
