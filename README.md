# aiTrade

토스증권·한국투자증권(KIS) API와 AI를 활용하는 개인용 주식 투자·자동매매 프로젝트입니다.

## 목표

- 작은 기능부터 만들고, 실제 필요와 측정된 문제에 따라 기능과 구조를 개선합니다.
- 기능별 문제·해결 방법·개선 전후 수치·최종 결과를 기록합니다.
- 초기에는 개인 환경에서 운영합니다.

## 실행 환경과 증권사 역할

- 노트북에서 Docker로 실행하고 집 Wi-Fi에 연결된 PC·휴대폰에서 사용합니다.
- 개인 사용자 1명이 간단한 로그인으로 사용합니다.
- **토스증권:** 시세·계좌 정보 조회와 실제 주식 주문
- **KIS:** 실전 계좌를 통한 정보 조회 전용. 토스에서 부족한 정보를 보완

현재는 **요구사항 문서화와 전체 UI/UX 프로토타입 검토 단계**입니다. 제품 구현 코드와 실행 설정은 아직 없습니다.

전체 화면과 주요 동작은 [`design/`](design/)의 고해상도 클릭형 프로토타입으로 검토합니다. 프로토타입은 모의 데이터만 사용하며 실제 증권사 API·계좌·주문과 연결되지 않습니다.

원화 환산 검토에는 검토용 고정 환율 **1 USD = 1,350원, 기준 시각 2026.09.22 10:30 KST**를 적용합니다. 모의 주문·정정도 원화 입력으로 시연하며, 실제 환율 조회와 주문 연동은 구현 전입니다.

## 단계별 범위

| 단계 | 핵심 기능 |
|---|---|
| 1차 | 국내 주식·국내 ETF·미국 주식 검색과 관심종목 관리, 실시간 시세·장 상태 확인 |
| 2차 | 보유종목·주문·거래내역 조회, 토스증권 지정가 수동매매, 주문·체결 알림 |
| 3차 | 국내 주식·국내 ETF AI 자동매매, 개인·전체·AI별 투자 현황과 성과 관리 |

## 핵심 원칙

- 실제 주문은 토스 실계좌 하나를 사용하고, 앱 장부에서 개인과 각 AI의 현금·보유·주문·거래·성과를 구분합니다.
- 화면의 모든 금액은 **원 단위(KRW)**로 표시합니다. 해외 종목의 가격·등락 금액·평균매입가·평가액·손익·주문·거래 금액도 환율을 반영해 표시하며, 원통화 금액과 적용 환율·기준 시각은 내부 기록에 보존합니다. 표시 환산은 실제 환전과 구분합니다.
- 과거 거래는 당시 기록된 환율을 유지하고, 자산·보유 요약은 같은 평가 시점의 환율로 합산합니다. 주문·정정 가격은 원화 입력을 기본으로 하며, 실제 USD 주문가격 변환·환율 적용 시점·호가단위 등 API 확인 사항은 [요구사항](docs/REQUIREMENTS_AND_DESIGN.md)에서 관리합니다.
- AI 트레이더는 하나의 생성 화면에서 **기본정보·종목 선정 방식·투자대상**을 입력한 뒤 생성합니다. 투자대상은 기본값인 **AI 선정** 또는 여러 종목을 지정하는 **직접 선택**으로 정합니다.
- AI 선정에서는 매 판단마다 투자 범위 안에서 후보를 자율 탐색하고, 직접 선택에서는 지정한 종목 안에서 판단·매매합니다. 직접 선택 목록은 트레이더마다 보존하며 개인 관심목록과 독립적으로 관리합니다.
- 생성한 트레이더·초안의 상세에서 종목 선정 방식과 투자대상을 수정할 수 있습니다. 저장하면 해당 트레이더의 투자대상 설정만 갱신하고, 취소하면 기존 설정을 유지합니다. 프로토타입은 모의 저장을 시연하며 실제 운영 중 변경 적용 시점과 기존 보유·미체결 주문 처리 정책은 [요구사항](docs/REQUIREMENTS_AND_DESIGN.md)의 보류 사항입니다.
- 여러 AI 트레이더를 지원하며, 초기에는 중기 트레이더 1명과 전략 1개로 시작합니다.
- 캐시·Redis·메시지큐 등의 구조는 실제 필요가 확인된 뒤 도입합니다.
