# 디자인 시스템

## 방향

- 기본 테마는 다크모드다.
- 금융 정보의 밀도는 유지하되, 위험 동작은 일상 조회 동작보다 명확하게 분리한다.
- 상승은 빨강, 하락은 파랑, 보합은 회색으로 표시하며 부호와 문구를 함께 사용한다.
- 색만으로 상태를 구분하지 않고 아이콘·텍스트·형태를 함께 사용한다.
- PC와 모바일에서 정보 구조와 용어를 유지하고 배치만 바꾼다.

## 공통 컴포넌트

- 앱 셸: PC 좌측 내비게이션, 모바일 하단 내비게이션
- 시장 상태 카드: 시장·세션·시간대·다음 세션·조회 상태
- 종목 행: 이름·코드·시장·현재가·등락·수신 상태
- 상태 배지: 실시간·주기 조회·지연·접수·부분체결·실행·중지
- 요약 카드: 대표 자산·TWR·현금·손익·낙폭
- 상세 패널: PC 우측 고정 열, 모바일 전체 화면 레이어
- 확인 대화상자: 주문 제출·정정·취소·AI 중지·자금 이동
- 데이터 표: 숫자 우측 정렬, 통화와 기준 시각 명시

## 반응형 기준

- `1200px 이상`: 목록과 종목 상세를 2열로 표시한다.
- `768px 이상 1199px 이하`: 축소된 좌측 내비게이션과 단일 콘텐츠 열을 사용한다.
- `767px 이하`: 상단 요약을 단순화하고 하단 내비게이션을 사용한다. 종목 상세와 검색은 전체 너비 레이어로 연다.

이 수치는 프로토타입 검토 기준이며 실제 React 구현에서 콘텐츠 측정 결과에 따라 조정할 수 있다.

## 동작 원칙

- 주문·자금 이동·AI 중지는 최종 확인 전에는 상태를 변경하지 않는다.
- 접수 결과가 불명확한 주문은 자동 재전송하지 않는다.
- AI 중지 처리 중에는 수동 매도와 자동매매 재개를 비활성화한다.
- 장부 불일치 시 모든 AI 신규 주문을 차단하되 기존 주문 상태 확인은 유지한다.
- `미정`·`보류`·`API 확인 필요` 값은 입력 항목으로 창작하지 않고 안내 또는 비활성 상태로 표시한다.
