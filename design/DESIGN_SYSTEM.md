# 디자인 시스템

## 방향

- 기본 테마는 다크모드다.
- 영역은 표면의 명도·간격·글자 위계로 구분한다.
- 카드·패널·버튼·입력·배지·대화상자의 장식 테두리와 표·앱 셸의 구분선은 생략한다.
- 키보드 포커스와 차트·판단 기록·아이콘의 의미 있는 선은 유지한다.
- 앱의 기본 표면은 짙은 중립색으로 유지하고 상태 문구는 흰색·회색으로 표시한다.
- 민트색은 주요 행동과 AI 선택 표시처럼 제한된 그래픽 요소에만 사용한다.
- 한글·영문·숫자의 기본 글꼴은 Pretendard로 통일한다.
- 금융 정보의 밀도는 유지하되, 위험 동작은 일상 조회 동작보다 명확하게 분리한다.
- 상승은 빨강, 하락은 파랑, 보합은 회색으로 표시하며 부호와 문구를 함께 사용한다.
- 상태는 색·아이콘·텍스트·형태를 함께 사용해 구분한다.
- PC와 모바일에서 정보 구조와 용어를 유지하고 배치만 바꾼다.

## 공통 컴포넌트

### 앱 셸과 탐색

- aiTrade 로고는 PC·모바일 상단에만 표시한다.
- 모바일은 하단 내비게이션을 사용한다.
- PC 메뉴 안쪽 상단의 패널 접기 버튼으로 226px 이름 표시 메뉴와 82px 아이콘 메뉴를 전환하며, 버튼의 이름·펼침 상태도 함께 갱신한다.
- 메뉴 접기 버튼은 44px로 표시한다. 상단 바와 높이가 같은 60px 행 안에서 오른쪽 기준 위치를 유지한다.
- 메뉴를 접거나 펼쳐도 로고의 왼쪽 위치는 유지한다.
- PC·모바일 메뉴에는 [Lucide](https://lucide.dev/)의 `chart-candlestick`(종목), `chart-pie`(투자 현황), `bot`(AI 트레이더)를 사용한다.
- 메뉴 아이콘 규격은 22px SVG·1.75 선 굵기·현재 글자색이다. 버튼 이름·접힌 상태 툴팁으로 의미를 안내한다.
- 접기 제어는 `panel-right-close`를 사용하고 내부 화살표만 상태에 맞춰 회전한다.
- [라이선스](licenses/lucide-LICENSE.txt)를 함께 보관한다.

### 종목과 주문

- 시장 상태 카드: 시장·세션·시간대·다음 세션·조회 상태
- 종목 행: 이름·코드·시장·현재가·등락
- 시세 연결이 끊기면 종목 행의 현재가 아래에 표시한다. 종목별 수신 시각은 상세에 표시한다.
- 지연 시간 문구는 종목 목록·상세에 표시하지 않는다.
- 상태 배지: 장 상태·시세 지연·연결 끊김·접수·부분체결·실행·중지
- 상세 패널: PC 우측 고정 열·모바일 전체 화면 레이어에 닫기 버튼을 제공한다.
- 모바일 상세에서는 배경 비활성·포커스 순환을 적용한다.
- 확인 대화상자: 주문 제출·정정·취소·AI 중지·자금 이동

### 새 알림

- 새 항목을 처음 표시하면 민트 배경으로 강조한 뒤 1600ms 동안 기존 어두운 표면으로 되돌린다.
- 알림창이 닫힌 동안 새 내용이 생기면 다음 열기에서 한 번 강조한다.
- 같은 알림을 재개방·화면 전환으로 다시 표시할 때는 강조를 반복하지 않는다.
- 동작 줄이기 설정에서는 알림 배경 전환을 생략한다.
- 프로토타입은 최신 모의 알림의 내용 변경으로 새 항목을 구분하며 제품에서는 알림 이벤트 ID를 사용한다.

### 검색·정정·순서 변경

- 정정 입력 대화상자: 선택 주문의 주체·가격·체결·잔여수량을 보여주고 미체결 가격·잔여수량을 입력한다.
- 정정의 최종 확인은 공통 확인 대화상자를 사용한다.
- 고정 검색 대화상자: 입력·범위·결과·단축키 영역을 고정하고 결과만 스크롤
- 순서 변경 대화상자는 기본 목록 레이아웃을 유지한다. 마우스·터치 드래그 또는 키보드 위·아래 화살표로 임시 순서를 편집한다.
- 순서 변경을 저장하면 목록에 반영한다.
- 드래그 중에는 잡은 행을 82% 불투명도의 복제본으로 표시한다. 복제본의 가로 위치는 고정하고 목록의 보이는 영역 안에서 위아래로만 이동한다.
- 복제본이 들어갈 자리에 같은 높이의 민트색 자리 표시자를 둔다. 점선은 생략한다.
- 복제본은 클릭·포커스·보조 기술에서 제외하고 종료·취소 시 제거한다.
- 항목 제거는 44px 버튼의 Lucide `trash` 아이콘으로 표시하며 접근 가능한 이름·툴팁에 종목과 제거 용도를 적는다.
- 순서를 변경하면 새 위치를 보조 기술에 알린다.

### AI 트레이더

- 트레이더 선택은 PC 우측 내비게이션 목록·모바일 하단 AI 메뉴의 선택 패널을 사용한다.
- PC 메뉴가 접혀 있으면 목록을 메뉴 왼쪽에 띄우고 바깥 클릭·Escape로 닫는다.
- 모바일 선택 패널도 바깥 클릭·Escape로 닫는다.
- AI 목록 화살표는 18px SVG의 중앙을 기준으로 회전한다. PC 목록의 열기·닫기는 160ms로 전환한다.
- 닫힌 목록은 키보드 포커스와 보조 기술에서 제외한다.
- 선택 항목은 강조 배경과 글자로 표시하고, 본문에는 선택한 트레이더의 상세만 표시한다.
- 트레이더 아바타는 투자 유형을 대문자 한 글자로 표시한다.
- 초단타 `S`, 중기 `M`, 장기 `L`을 기존 트레이더·생성 초안·상세에 공통 적용한다.
- AI 트레이더 메뉴 항목은 유형·상태를 보여주고 선택하는 용도로 사용한다.
- 목록 끝의 추가 버튼에서 새 트레이더를 만들고, 기존 트레이더와 초안의 이름 수정은 모두 선택 후 상세 상단에서 진행한다.
- 기존 트레이더와 생성 초안의 상세는 같은 자산 요약·시간가중수익률·판단 기록·보유종목 영역을 재사용한다.
- 초안에는 초기 현금과 빈 성과·기록·보유 상태를 표시한다.
- 생성 시 저장한 종목 선정 방식·투자 대상도 트레이더별로 표시한다.
- AI 상세·초안의 수치 카드는 숫자·설명 글자 크기와 여섯 항목을 유지하면서 세로 여백을 줄인다.
- 수치 카드 최소 높이: PC 112px, 820px 이하 100px, 420px 이하 92px. 줄바꿈 시 높이를 늘린다.
- 수치 카드 간격: 세로 패딩 PC 13px·모바일 12px, 요약 위 여백 16px, 숫자 위 여백 6px.

### TWR 차트

- 화면 진입·트레이더 변경 후 차트가 보이기 시작하면 선·채움이 0% 기준선에서 580ms 동안 올라온다.
- 차트 눈금·축은 고정한다. 같은 차트의 탭·상태 재렌더에는 진입 전환을 반복하지 않는다.
- 선 아래는 같은 곡선을 공유하는 민트 그라데이션과 흐린 빛으로 은은하게 채운다.
- 시점 탐색을 시작하면 진입 전환을 즉시 끝내 실제 기록 위치에서 툴팁을 표시한다.
- 동작 줄이기 설정에서는 TWR 차트를 즉시 최종 형태로 표시한다.

### 계좌 내역과 금액

- 투자 현황·AI 상세의 자산 요약은 같은 계산값을 사용해 총 자산·미투자 현금·투자금·보유 평가액·평가 순손익·보유 수익률을 여섯 카드에 표시한다.
- AI별 TWR은 트레이더 상세 그래프에 표시한다.
- 투자 현황의 전체·개인과 AI 트레이더별 상세는 보유종목·손익·주문·거래 탭을 같은 컴포넌트로 표시한다.
- 투자 현황 상단에는 전체·개인만 두고 개별 AI는 AI 트레이더 목록에서 선택한다.
- 종목의 관심·보유와 공통 계좌 내역 탭은 회색 선택 배경만 새 버튼의 위치·폭으로 160ms 동안 이동한다.
- 글자·포커스는 고정하고, 빠른 재선택은 이동 중 위치에서 이어진다.
- 첫 표시·같은 탭 선택·주체 변경·동작 줄이기 설정에서는 탭 배경을 즉시 표시한다.
- 창·메뉴 너비·글꼴이 바뀌면 탭 배경을 재측정한다.
- 주문·거래는 공통 계좌 내역에서 제공한다.
- 주문 표에서 정정·취소 확인 흐름을 연다.
- 거래내역은 처음 10건을 표시한다. 내부 스크롤 하단에 도달하면 다음 10건을 기존 목록 뒤에 추가한다.
- 거래내역의 더 보기 버튼도 다음 10건을 추가한다. 기록을 추가해도 읽던 위치는 유지한다.
- 기존 기간·시장 조회 조건과 주문 단위 집계는 유지한다.
- 거래내역의 높이 조절·내부 스크롤 구조는 전체·개인·AI 트레이더·초안에 공통 사용하고, 빈 결과에도 높이 조절 손잡이를 둔다.
- 주체별 뷰 높이·불러온 수·스크롤 위치를 화면 전환 동안 유지한다.
- 기간·시장 조회를 적용하면 거래내역을 처음 10건으로 초기화하고 스크롤을 맨 위로 옮긴다. 뷰 높이는 유지한다.
- 주문 표의 `관리` 제목과 정정·취소 버튼 묶음은 같은 열 중앙에 정렬한다.
- 정정·취소 버튼의 크기는 유지하고 양쪽 여백을 확보한다.
- 주문·거래 표가 화면보다 넓으면 PC·모바일 모두 표 안에서 가로 스크롤한다.
- 보유 표에는 같은 종목 목록 시세를 사용한 현재가를 평균매입가 옆에 표시한다.
- 지연·연결 끊김 상태는 현재가 아래에 표시한다.
- 가격·평균매입가·평가금액·비용 전 평가손익은 같은 평가 환율로 원화 환산하고 수익률은 원래 시세 기준을 유지한다.
- 금액 단위는 숫자 오른쪽의 `원`으로 통일하고, 전체 평균매입가는 투자 주체별 보유수량을 가중한다.
- 주문·거래 표는 같은 열 너비를 사용하고, 주문의 체결·잔여수량은 주문수량 아래에 표시한다.
- 좁은 화면에서는 표마다 가로 스크롤한다.
- 금액은 계산 후 마지막 표시 단계에서 원 단위로 반올림한다.
- 시세 등락금액은 현재가와 기준가격에 같은 환율을 적용한다.
- 해외 주문·정정도 원 단위 정수를 입력하며, 실제 주문 통화 변환·호가 검증은 API 확인 전이다.
- 과거 거래·관련 알림은 기록별 환율을 보존한다. 환율이 누락되면 `확인 불가`로 표시한다.
- 손익 표의 금액 칸은 숫자와 `원`만 표시한다.
- 실현분은 체결 기준, 평가분은 예상값, 총손익은 두 항목의 합계라는 설명을 표 아래에 둔다.

### AI 생성과 투자 대상

- 초안 상세의 이름 수정·자금 관리·자동매매 시작은 기존 상세와 같은 위치에 둔다.
- 전략 확정 전에는 자동매매 시작 버튼을 비활성화한다.
- 생성 대화상자는 개인 사용 가능 현금과 초과 입력 오류를 보여준다.
- AI 트레이더 생성 대화상자는 기본 정보(이름·유형·배정금)와 투자 대상을 한 화면에서 입력한다.
- 이름·유형·배정금은 빈 상태에서 시작하고 `트레이더 만들기`로 모든 입력을 검증한 뒤 생성을 완료한다.
- 생성 입력에 오류가 있으면 대화상자 안에 빨간 원형 아이콘·문구로 표시하고 해당 입력으로 포커스를 옮긴다.
- 생성 대화상자는 최대 560px 너비를 사용하고 긴 본문만 내부 스크롤한다.
- 제목과 취소·생성 버튼은 유지하며, 선택 종목·추가 방법·하단 버튼의 조작 영역은 최소 44px로 둔다.
- 종목 검색에서 Enter를 눌러도 생성 제출은 실행하지 않는다.
- 종목 선정 방식 전환 시 직접 선택 영역의 높이·위 간격은 180ms, 투명도는 140ms로 열고 닫는다.
- 창 높이도 본문과 함께 자연스럽게 바뀌며 최대 높이에서는 내부 스크롤을 사용한다.
- 직접 선택 영역을 접으면 즉시 키보드 조작·보조 기술에서 제외한다.
- 선정 방식을 빠르게 재선택하면 진행 중 위치에서 전환을 이어간다.
- 동작 줄이기 설정에서는 직접 선택 영역을 즉시 전환한다.
- 종목 선정 방식은 기본 `종목 선택하지 않음`과 `직접 선택`을 제공한다.
- 기본 방식은 AI가 허용 투자범위에서 판단마다 후보를 선정한다.
- 직접 선택에서는 검색·기존 개인 관심종목으로 여러 종목을 추가하고 목록에서 제거할 수 있다.
- 직접 선택 종목의 중복 추가를 차단한다. 생성 시 최소 1개를 선택했는지 검사한다.
- 직접 선택 방식은 저장한 종목만 투자 대상으로 사용한다.
- 첫 자동매매 범위인 국내 주식·ETF만 선택 가능하며 미국은 후속 지원을 안내한다.
- 선정 방식·추가 방법을 전환하면 생성 입력·임시 선택 목록을 유지한다.
- 생성창을 취소·닫기하면 입력 검사 없이 종료하고 임시값을 폐기한다.
- 생성창을 다시 열면 빈 기본 정보·기본 선정 방식으로 시작한다.
- 생성 시 선정 방식·직접 선택 목록을 해당 트레이더에 모의 저장하고 개인 관심목록은 유지한다.
- 기존 트레이더·초안의 투자 대상 영역에 44px 수정 버튼을 둔다.
- 편집창은 현재 선정 방식·종목의 복사본을 불러오고 투자 대상만 표시한다.
- 투자 대상 수정을 저장하면 해당 트레이더의 선정 방식·목록을 갱신한다.
- 수정창을 취소·닫기하면 원본을 유지한다.
- 직접 선택은 최소 1개를 검증하고 AI 선정은 빈 직접 선택 목록으로 저장한다.

### 판단 기록과 높이 조절

- 판단 기록은 완전한 원형 점·1px 연결선을 사용한다.
- 최신 기록의 점만 민트색으로 강조하고, 다음 점까지의 연결선은 민트색에서 기존 중립색으로 점차 옅어진다.
- 나머지 점과 연결선은 중립색을 유지한다.
- 판단 제목 옆에 매수·매도·기타 분류와 종목명 배지를 표시한다.
- 매수는 기존 매수 색, 매도는 기존 매도 색, 기타·운영은 중립색으로 두고 문구를 함께 제공한다.
- 복수 보유 점검은 종목별 배지를 표시하고 제목에서 종목 반복을 줄인다.
- 배지는 비조작 요소이며 긴 이름과 좁은 화면에서 줄바꿈한다.
- 모바일은 날짜를 본문 위에 두어 설명 폭을 확보한다.

### 기록 뷰 높이와 이어보기

- 판단 기록·거래내역의 공통 뷰 높이: 기본 280px, 최소 160px, 최대 `max(160px, min(640px, 75vh))`.
- 창이 낮을 때도 기록 뷰의 최대 높이는 최소 높이 이상을 유지한다.
- 하단 44px 손잡이를 위아래로 드래그해 높이를 조절한다.
- 키보드 위 화살표는 32px 줄이고 아래 화살표는 32px 늘리며, Home·End는 최소·최대 높이로 이동한다.
- 손잡이에 각 영역의 조작 이름과 현재 높이를 제공하고 키보드 포커스를 표시한다.
- 창 높이가 바뀌면 허용 높이 범위에 맞춘다.
- 드래그 포인터를 화면 상하단 48px 안에 유지하면 페이지를 함께 스크롤하며 높이를 조절한다.
- 상단 바·모바일 메뉴 영역을 제외하고 최소·최대 높이에서 멈춘다.
- 드래그 중에는 페이지 높이를 유지해 페이지 맨 아래에서 과도하게 축소되는 것을 막는다.
- 드래그를 취소하면 뷰 높이·내부 스크롤·페이지 위치를 복원한다.
- 키보드 조절 후에도 손잡이를 화면 안에 유지한다.
- 판단 기록은 최신순으로 처음 10건을 표시한다.
- 판단 기록 내부 스크롤 하단에 도달하거나 더 보기를 선택하면 과거 10건을 기존 목록 뒤에 추가한다. 기간 검색은 제공하지 않는다.
- 화면을 전환하면 트레이더별 판단 기록 뷰 높이·불러온 수·스크롤 위치를 유지한다.
- 창 높이가 바뀌면 판단 기록 뷰를 허용 높이 범위에 맞춘다.
- 새 초안도 같은 기록 영역과 빈 상태를 사용한다.

### 데이터·입력·포커스

- 데이터 표: 숫자 우측 정렬, 통화와 기준 시각 명시
- 단위가 붙은 입력은 전체 입력 상자에 키보드 포커스 윤곽선을 표시한다. 기본 입력 면은 밝은 중립색, 오류는 붉은 배경·문구로 구분한다.
- 입력·선택 카드·버튼의 포커스 윤곽선은 2px 두께로 요소 안쪽에 표시한다.
- 단위 입력·검색창은 입력 묶음 전체에 표시하며, 스크롤 영역의 첫·마지막 항목과 좌우 경계에서도 잘리지 않게 한다.
- 오류 입력은 붉은 윤곽선을 유지한다.
- 투자 유형·종목 선정 방식 카드에 마우스를 올리면 중립 표면을 밝게 하고 선택된 카드의 민트 배경을 진하게 한다.
- 카드 배경은 120ms로 전환한다. 크기·위치는 유지한다.
- 동작 줄이기 설정에서는 카드 배경을 즉시 표시한다.
- 오류·비활성 카드에는 호버 강조를 적용하지 않는다.
- 선택 종목·탭·매수/매도·자금 이동 방향도 같은 표면 변화 원칙을 따르고 기존 선택·매매 색상을 유지한다.

- 화면의 공통 구조는 앱 셸, 표·행, 종목 상세, 대화상자, 단위 입력, 상태 배지로 나누고 이 문서의 토큰·반응형 기준과 문구를 재사용한다.
- 주문 제출·정정·취소는 동일한 확인 대화상자와 요약 행을 사용한다.
- 주문 정정의 선택 주문, 편집 초안, 최종 확인, 결과 조회를 별도 상태로 다룬다.
- 프로토타입의 `previewOrders` 변경은 화면 시연 전용이며 실제 구현의 API 응답·주문 상태로 대체한다.
- AI 트레이더 이름은 내부 식별자와 분리된 표시값으로 다룬다.
- 이름 수정 시 공통 입력 대화상자를 재사용하고, 투자 현황·주문·거래에는 같은 트레이더 식별자로 연결된 새 이름을 표시한다.
- AI 트레이더의 종목 선정 방식·직접 선택 목록은 트레이더 식별자별 설정으로 다룬다.
- 생성 중 임시값과 개인 관심목록을 별도로 관리하고 완료 시 해당 트레이더에 저장한다.
- 실제 백엔드의 설정 저장·허용 투자범위 적용·판단 후보 선정은 미구현이다.
- 전략 기준·실주문 API의 확인 상태는 기존 요구사항을 따른다.
- 자산·보유 투자 요약은 투자 주체별 자산·현금·현재 보유분 원가·평가액·비용 반영 평가손익을 같은 데이터 모델에서 계산해 두 화면에 재사용한다.
- 최초 배정금은 생성·이력 데이터로 유지하고 요약에는 넣지 않는다.
- TWR 그래프의 선과 툴팁은 동일한 평가 기록 목록의 시각·수익률에서 만든다.
- React 구현에서는 모의 배열을 서버 평가 기록으로 바꾸되 기록 사이 값을 새로 생성하지 않는다.
- 최근 판단 기록의 모의 이어보기는 제품 구현에서 커서 기반 기록 API 조회로 대체한다.
- 트레이더별 조회 상태와 기록 ID를 사용해 기존 목록 뒤에 추가하고, 중복 기록·페이지 종료를 실제 API 응답으로 확인한다.
- 기록 영역의 높이·불러온 범위·스크롤 위치는 트레이더별로 유지한다.
- 거래내역의 모의 이어보기는 제품 구현에서 실제 거래내역 페이지 조회로 대체한다.
- 기존 기간·시장 조건과 주체별 조회 상태를 연결하고, 중복·마지막 페이지를 API 응답으로 확인한다.
- 내부 스크롤·높이 조절은 조회 방식과 분리해 유지한다.
- API 지원 여부가 확인되면 종목·세션·주문별 허용 필드와 검증 범위를 주문 데이터에서 받아 입력 활성화에 사용한다.
- API 지원 여부 확인 전에는 실제 정정 제출을 비활성화한다.

## 동작 원칙

- 주문·자금 이동·AI 중지는 최종 확인 전에는 상태를 변경하지 않는다.
- 주문 접수 결과가 불명확하면 자동 재전송하지 않는다.
- AI 중지 처리 중에는 수동 매도와 자동매매 재개를 비활성화한다.
- 장부 불일치 시 모든 AI 신규 주문을 차단하고 기존 주문의 상태 확인은 유지한다.
- 장부 재대조 후에도 각 AI 트레이더의 자동매매는 사용자가 직접 재개할 때까지 중지 상태를 유지한다.
- 모의 데이터 기준 시각은 화면 전체에 하나만 사용하고 실제 현재 시각처럼 흐르게 하지 않는다.
- 투자 현황·AI 상세의 보유 수익률 = 현재 보유분의 평가 순손익 ÷ 투자금(매입원가).
- 보유 평가액은 비용 차감 전 시가이므로 평가 순손익과의 차이를 설명한다.
- 현금·실현손익과 AI의 시간가중수익률을 한 지표로 섞지 않는다.
- AI TWR 그래프는 해당 트레이더의 최초 배정 이후 기록만 표시한다.
- 운용 시작 전 날짜나 정상 fixture에 임의의 `기록 없음` 구간을 넣지 않는다.
- AI TWR 그래프는 커서·터치 시 가장 가까운 평가 기록의 KST 시각과 수익률을 툴팁에 표시한다.
- 키보드 포커스에서 좌우 화살표와 Home·End로 기록을 탐색한다.
- 툴팁은 실제 기록값만 보여주며 중간 시각의 값을 만들지 않는다.
- 선택한 종목·주문·투자 주체를 확인·상세·다음 화면에 그대로 전달한다.
- 자산·현금·성과 요약과 하위 내역도 같은 주체 기준으로 갱신한다.
- `미정`·`보류`·`API 확인 필요` 값은 안내 또는 비활성 상태로 표시하며 입력 항목을 임의로 만들지 않는다.

### 공통 화면 전환

- 새로고침·화면 전환 시 우측·상단 내비게이션과 콘텐츠를 제자리에 즉시 표시한다. 진입 애니메이션은 사용하지 않는다.
- 실행 중 동작 줄이기 설정을 켜면 알림·차트의 진입 효과와 탭 선택 배경 이동·종목 상세 전환을 즉시 끝내고, 다시 꺼도 같은 효과를 재생하지 않는다.
- 전환 종료 이벤트·동작 줄이기 설정 변경 시 전환 상태를 정리한다.
- 사용자 선택으로 연 대화상자는 배경 화면의 위치와 너비를 바꾸지 않는다.
- 마우스를 사용할 때 선택된 주요 메뉴와 AI 트레이더 항목에도 hover 반응을 표시한다.
