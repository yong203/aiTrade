# aiTrade UI/UX 프로토타입

이 폴더는 aiTrade 전체 제품의 고해상도 UI/UX와 핵심 동작을 검토하기 위한 클릭형 프로토타입을 관리한다. 확정된 화면 구조·상태·컴포넌트·표시 규칙은 프론트엔드 구현의 기준으로 사용한다.

현재 상태는 **전문 분야별 사용성 점검을 반영한 검토용 초안**이다. 기능 요구사항의 기준은 [요구사항](../docs/REQUIREMENTS_AND_DESIGN.md)이며, 프로토타입 검토에서 합의한 제품 동작 변경은 요구사항 문서와 요구사항 추적표에 함께 반영한다.

## 실행

프로젝트 루트에서 다음 명령을 실행한다.

```bash
python3 -m http.server 4173 --directory design
```

브라우저에서 `http://localhost:4173`을 연다. 외부 API, 실제 계좌, 실제 주문과 연결되지 않으며 모든 값과 동작은 검토용 예시다. 화면의 모의 기준 시각은 **2026.09.22 10:32 KST**로 고정되어 있다.

## 포함 화면

- 종목: 국내·미국 장 상태, 관심·보유 목록, 종목 검색·추가·제거·순서 변경, 종목 상세와 지정가 주문
- 투자 현황: 전체·개인별 총 자산·미투자 현금·투자금·보유 평가액·평가 순손익·보유 수익률, 종목별 현재가·평균매입가·평가손익·수익률, 주문 상태와 모의 정정·취소, 거래내역 기간·시장 조회와 내부 스크롤 이어보기·높이 조절
- AI 트레이더: 우측 메뉴(모바일 하단 AI 트레이더 메뉴)에서 트레이더·초안 선택, 한 화면에서 기본정보·투자 대상 입력과 생성, 종목 선정 방식·투자 대상 표시와 수정, 투자 현황과 같은 자산·보유 투자 요약, 트레이더별 TWR 추이, 기존 상세와 같은 구조의 생성 초안·빈 상태 및 이름 수정, 개인 사용 가능 현금 한도 내 최초 배정, 운용 전·중지 완료 후 추가 배정·회수 모의 이동, 판단 기록과 보유, 중지·재개, 장부 대조 상태
- 공통 상태: 로딩·빈 상태·오류·연결 끊김·지원 확인 전·장부 불일치
- 반응형: PC의 우측 상세 패널과 모바일의 전체 너비 상세 화면·하단 내비게이션

## 2차 초안에서 달라진 점

- 카드·표·앱 셸·버튼·입력·배지·대화상자의 장식 테두리와 구분선을 제거하고 배경색·간격으로 영역을 구분한다. 입력·보조 버튼의 면과 hover 배경은 유지하며 오류는 붉은 배경과 문구로 안내한다. 키보드 포커스·차트·판단 기록·아이콘의 선은 유지한다.

- 프로토타입 전용 막대를 제거하고 상태 선택기를 앱 상단에 작게 통합했다.
- aiTrade 로고는 PC·모바일 상단에만 표시한다. 메뉴 안쪽 상단에 접기·펼치기 버튼을 두고, 접으면 아이콘 메뉴와 왼쪽으로 열리는 AI 트레이더 목록을 사용한다. 접힌 메뉴의 목록과 모바일 선택 패널은 바깥 클릭·Escape로 닫힌다. 메뉴 폭이 바뀌어도 상단 로고와 접기 버튼의 위치는 유지한다. 메뉴는 Lucide SVG 시세 차트·자산 구성·AI 로봇 아이콘을 PC·모바일에서 공통 사용한다. AI 화살표는 같은 중앙 위치에서 회전하며, 메뉴 폭과 PC AI 트레이더 목록은 160ms 동안 전환한다.
- 더 어두운 중립 표면과 Pretendard를 사용하고, 상태 문구는 흰색·회색으로 통일했다. 상태는 낮은 채도의 배지 배경으로 구분하고 기존 민트색은 주요 행동·AI 선택 표시에 사용한다.
- 화면 제목 주변의 반복 설명과 영문 레이블을 줄여 핵심 데이터가 먼저 보이게 했다.
- 종목 검색은 결과 수·로딩·빈 상태·오류 상태와 관계없이 같은 크기를 유지하고 결과 영역만 스크롤한다. 검색·순서 변경·주문 정정·확인·AI 생성·투자 대상 수정·이름 수정·자금 관리 대화상자는 열기·닫기와 배경 어두움·흐림에 140ms 전환을 공통 적용한다. 알림·모바일 AI 목록에도 짧은 전환을 적용하며, 동작 줄이기 설정에서는 즉시 전환한다.
- 종목 목록의 수신 상태 열과 반복 수신 시각·조회 주기를 제거했다. 종목 목록·상세에는 지연 시간 문구를 표시하지 않고, 연결 끊김과 상세의 실제 수신 시각은 유지한다.
- 관심·보유 탭 선택 시에는 상세를 닫고 목록만 표시한다. 첫 종목 상세를 자동으로 열지 않으며, 목록에서 종목을 직접 눌러 상세를 연다.
- 가격·등락금액·평균매입가·평가금액·손익·주문·거래·알림의 금액은 모두 숫자 오른쪽에 `원`으로 표시한다. 해외 시세는 모의 환율 **1달러 = 1,350원**, **2026.09.22 10:30 KST**를 적용하고 계산 후 표시 단계에서 반올림한다. 등락률은 원래 시세 기준을 유지한다. 이미 원화인 요약·세금·수수료는 다시 환산하지 않는다.
- 해외 주문·정정은 원 단위 정수 입력으로 시연한다. 원래 USD 주문가격은 보존하고 원화 정정값을 따로 저장한다. 실제 USD 변환·호가단위 검증은 API 확인 필요다. 거래 기록별 모의 환율은 각 기록에 저장하며, 환율이 없는 기록은 `확인 불가`로 표시한다.
- 종목 상세는 PC와 모바일 모두 닫기 버튼을 제공하며, 열고 닫을 때 180ms 동안 살짝 이동하며 나타나고 사라진다. PC 목록 폭과 세로 배치의 상세 높이도 함께 전환한다. 주문 종류 변경에는 반복하지 않으며 동작 줄이기 설정에서는 즉시 전환한다. 주문 화면에서는 보유수량·평균매입가와 가격·수량·예상 주문금액에 집중하고, 비용·손익은 투자 현황의 손익 탭에서 확인한다.
- 관심종목 순서 변경은 별도 대화상자에서 드래그로 임시 순서를 편집한다. 잡은 행은 약간 반투명한 상태로 목록의 보이는 영역 안에서 위아래로만 움직이고 들어갈 자리는 점선 없이 민트색으로 표시한다. 항목 제거는 휴지통 아이콘 버튼을 사용한다. 취소 시 원래 순서가 유지되고 저장 시에만 반영된다.
- 새로고침과 페이지 전환은 앱 셸과 콘텐츠를 진입 애니메이션 없이 제자리에 즉시 표시하며, 강제 부드러운 스크롤을 사용하지 않는다.

## 검토 방법

- 상단의 `PREVIEW` 선택기에서 정상, 시세 연결 끊김, 장 정보 실패, 주문 접수 확인 중, 장부 불일치 상태를 바꾼다.
- 종목 화면에서 관심·보유 탭, 종목 선택, 종목 추가, 순서 변경을 확인한다.
- 종목 상세에서 매수·매도, 가격·수량 입력, 주문 확인 흐름을 확인한다.
- 투자 현황에서 전체·개인을 전환하고, 우측 AI 트레이더 메뉴(모바일에서는 하단 AI 트레이더 메뉴)를 펼쳐 트레이더·초안 선택과 추가를 확인한다.
- PC에서 메뉴 안쪽 상단 버튼으로 접기·펼치기를 반복하고, 두 상태 모두에서 AI 트레이더 목록 선택·접기와 화살표 중앙 정렬을 확인한다.
- 투자 현황의 보유종목에서 평균매입가·평가손익·수익률을 확인하고, 주문·거래 탭에서 정정·취소와 거래내역 내부 스크롤 하단·더 보기의 추가 로딩을 확인한다. 거래내역 하단 손잡이와 키보드로 높이를 바꾸고, 전체·개인·AI·초안 전환 후 높이·불러온 수·읽던 위치가 유지되는지 확인한다. 기간·시장 조회를 적용하면 목록·스크롤은 처음으로 돌아가고 높이는 유지되는지, 빈 결과에도 손잡이가 있는지 확인한다.
- AI 트레이더 화면에서 기존 트레이더·생성 초안의 이름 수정, TWR 그래프의 시점별 값, 중지·재개와 자금 배정 흐름을 확인한다.
- AI 트레이더 추가의 한 화면에서 이름·유형·배정금과 투자 대상을 입력한다. 기본 `종목 선택하지 않음`과 `직접 선택`을 전환하고, 검색·개인 관심종목에서 여러 국내 종목을 추가·제거한다. 생성 시 기본정보 오류·사용 가능 현금 초과·직접 선택 0개가 차단되고 중복 종목을 추가할 수 없는지 확인한다. 모드 전환에서는 기본정보·선택 목록이 유지되고 닫기·취소 후 재개방에서는 초기화되는지 확인한다. 생성 후 상세에 선정 방식·대상이 표시되고 개인 관심목록은 유지되는지 확인한다.
- 기존 트레이더·초안 상세의 투자대상 영역에서 수정을 연다. 현재 선정 방식·종목이 표시되고, 모드 전환 중 임시 선택이 유지되는지 확인한다. 직접 선택 0개 저장은 차단되고 AI 선정 저장은 직접 선택 목록을 비우는지, 저장 후 해당 트레이더의 투자대상만 갱신되는지 확인한다. 취소·닫기 후 다시 열면 기존 설정이 표시되고 이름·유형·배정금·현금·보유·주문·개인 관심목록이 유지되는지 확인한다.
- 최근 판단 기록 하단의 손잡이를 드래그하거나 키보드 위·아래 화살표와 Home·End로 영역 높이를 바꾼다. 내부 스크롤 하단과 더 보기 버튼으로 과거 기록이 이어지는지, 다른 트레이더로 갔다 돌아왔을 때 높이·불러온 기록 수·읽던 위치가 유지되는지 확인한다. 새 초안에서는 같은 영역의 빈 기록 상태를 확인한다.

## 이번 사용성 점검 반영

- 검색에서 종목을 추가하고 닫으면 관심 목록과 개수가 즉시 갱신된다.
- 투자 주체 전환 시 여섯 자산·보유 투자 지표와 손익·보유·주문·거래내역 예시를 함께 전환한다. 보유 표는 일부 fixture이며 자산 요약과 합계가 다르다.
- 투자 현황의 전체·개인과 AI 상세는 총 자산·미투자 현금·투자금·보유 평가액·평가 순손익·보유 수익률을 같은 기준으로 표시한다. 보유종목·손익·주문·거래 탭을 같은 구조로 사용하고 실현손익은 손익 탭에서 분리한다. AI별 TWR 그래프는 각 트레이더 상세에 두며 커서·탭·키보드로 모의 평가 시각과 수익률을 확인한다. 최초 배정 전 날짜와 임의의 누락일은 표시하지 않는다.
- AI 선택 상태·현금·판단 기록·보유분을 트레이더별로 분리했다. 수동 매도는 클릭한 종목과 투자 주체로 이어진다.
- AI 트레이더·초안 상단의 여섯 수치 카드는 세로 높이와 여백을 줄여 차트를 더 가까이 표시한다. 숫자·설명 글자 크기와 표시 항목은 유지한다.
- 최근 판단 기록의 최신 점은 민트색으로 강조하고, 다음 점까지의 선만 기존 중립색으로 점차 옅어지게 표시한다. 나머지 점·선은 기존 색을 유지한다.
- 판단 제목 옆에 매수·매도·기타와 종목명 배지를 표시한다. 복수 보유 점검은 종목별로 표시하고 운영 기록은 운영 범위로 구분한다. 분류와 종목은 구조화된 모의 기록 정보에서 가져오며 모바일에서는 날짜를 본문 위에 둔다.
- 최근 판단 기록은 하단 손잡이와 키보드로 높이를 조절하고 영역 안에서 스크롤한다. 하단에 도달하거나 더 보기를 선택하면 과거 기록을 최신순 목록 뒤에 추가한다. 트레이더별 높이·불러온 수·스크롤 위치를 유지하며 기간 검색은 제공하지 않는다. 수치 규격은 [디자인 시스템](DESIGN_SYSTEM.md)을 따른다.
- 거래내역도 내부 스크롤과 하단 손잡이·키보드 높이 조절을 사용한다. 기존 기간·시장 필터를 유지하고, 전체·개인·AI·초안별 높이·불러온 수·읽던 위치를 유지한다. 조회 적용 시 목록 추가 범위와 스크롤만 초기화하고 높이는 유지한다. 빈 결과도 같은 높이 조절 구조를 사용하며 수치 규격은 [디자인 시스템](DESIGN_SYSTEM.md)을 따른다.
- 판단 기록·거래내역을 드래그할 때 화면 가장자리에 포인터를 유지하면 페이지가 함께 스크롤되어 높이를 계속 조절할 수 있다. 최소·최대 높이에서 멈추고 취소하면 원래 높이와 페이지 위치로 돌아간다.
- 관심·보유와 보유종목·손익·주문·거래 탭의 회색 선택 배경은 160ms 동안 새 위치·폭으로 이동한다. 연속 선택·모바일·글꼴과 너비 변경에 대응하고, 동작 줄이기 설정에서는 즉시 전환한다.
- 기존 AI 트레이더와 생성 초안의 이름을 수정할 수 있다. 이름 변경은 목록·상세·투자 현황·주문·거래 표시만 갱신하고 트레이더별 금액과 기록은 유지한다.
- 새 AI 트레이더는 하나의 생성 화면에서 기본 정보(이름·유형·배정금)와 종목 선정 방식·투자 대상을 입력하고 생성 시 함께 검증한다. 기본 `종목 선택하지 않음`은 AI가 허용 투자범위에서 판단마다 후보를 선정하는 방식이다. `직접 선택`은 검색·개인 관심종목에서 추가한 종목만 투자 대상으로 저장하며 최소 1개를 선택해야 한다. 국내 주식·ETF만 선택할 수 있고 미국은 후속 지원을 안내한다. 선정 방식·선택 목록은 트레이더별로 모의 저장해 상세에 표시하고 개인 관심목록은 변경하지 않는다.
- 기존 트레이더와 생성 초안의 투자대상도 상세에서 수정할 수 있다. 현재 설정으로 시작해 선정 방식·종목 목록만 모의 저장하고, 취소·닫기는 기존 설정을 유지한다. 직접 선택의 최소 1개·중복 방지·지원 범위 검사는 생성과 같은 기준을 사용하며, 수정 중 이름·투자 유형·자금·보유·주문은 유지한다.
- 주문 정정은 클릭한 주문의 미체결 가격·잔여수량을 입력하고 변경 전후를 확인한 뒤 목록에 모의 결과를 반영한다. 돌아가면 입력값을 유지하고, 취소하면 목록을 변경하지 않는다. 주문 취소는 대상 확인까지만 제공한다. 실제 주문·정정·취소는 API 확인 전이며 모든 버튼은 모의 흐름이다.
- 모바일 상세와 알림의 닫기·포커스 동작, 접힌 메뉴의 접근 가능한 이름, 키보드 순서 변경 안내를 보강했다.
- 알림창에서 최신 새 알림은 민트 배경에서 기존 어두운 배경으로 1600ms 동안 돌아온다. 첫 표시와 모의 알림 내용 변경 때만 적용하고, 다시 열 때 반복하지 않는다. 동작 줄이기 설정에서는 전환을 생략한다.
- TWR 차트는 화면 진입·트레이더 변경 후 차트가 보이기 시작하면 선과 은은한 민트 채움이 0% 기준선에서 580ms 동안 올라온다. 축·기록값은 유지하고, 같은 차트의 탭 전환에는 반복하지 않는다. 시점 탐색이나 동작 줄이기 설정에서는 최종 형태를 즉시 표시한다.

## 범위 경계

- 종목 가격 차트·호가창·시장가 주문·외부 알림은 현재 요구사항의 후속 범위이므로 설계하지 않는다. AI별 TWR 추이 그래프는 포함한다.
- API 지원 여부가 확인되지 않은 세션 주문과 비용·환율 값은 확정된 기능처럼 표현하지 않는다. 화면의 비용·수익률·AI 성과 그래프 숫자는 검토용 fixture다.
- AI 전략 기준·판단 주기 등 보류된 정책을 사용자가 입력하는 설정으로 임의 추가하지 않는다.
- AI 트레이더 생성과 투자대상 수정은 종목 선정 방식·투자대상의 입력과 모의 저장을 시연한다. 실제 백엔드의 설정 저장·허용 투자범위 적용·판단 후보 선정은 미구현이며 전략 기준은 보류 상태다. 실제 운영 중 투자대상 변경 적용 시점과 기존 보유종목·미체결 주문 처리 정책도 보류 상태다. 첫 자동매매 범위는 국내 주식·ETF이고 미국 자동매매는 후속 지원 범위다.
- 판단 기록 이어보기는 모의 기록을 추가하는 시연이다. 실제 기록 API를 호출하지 않으며, 제품 구현에서는 커서 조회·중복 제거·마지막 페이지 확인을 연결해야 한다.
- 거래내역 내부 이어보기도 모의 내역 시연이다. 실제 거래내역 API를 호출하지 않으며 기간·시장 조건의 페이지 조회·중복 제거·종료 신호는 제품 구현에서 연결해야 한다.
- 디자인 검토 중 확정된 제품 동작 변경은 `docs/REQUIREMENTS_AND_DESIGN.md`에 반영한 뒤 프로토타입과 동기화한다.
