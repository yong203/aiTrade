# aiTrade UI/UX 프로토타입

이 폴더는 aiTrade 전체 제품의 고해상도 UI/UX와 핵심 동작을 검토하기 위한 클릭형 프로토타입을 관리한다. 실제 React 제품 코드가 아니며, 확정된 화면 구조·상태·컴포넌트·표시 규칙을 프론트엔드 구현의 기준으로 사용한다.

## 실행

프로젝트 루트에서 다음 명령을 실행한다.

```bash
python3 -m http.server 4173 --directory design
```

브라우저에서 `http://localhost:4173`을 연다. 외부 API, 실제 계좌, 실제 주문과 연결되지 않으며 모든 값과 동작은 검토용 예시다.

## 포함 화면

- 종목: 국내·미국 장 상태, 관심·보유 목록, 종목 검색·추가·제거·순서 변경, 종목 상세와 지정가 주문
- 주문·거래: 주문 상태, 부분체결, 접수 확인 중, 정정·취소 진입점, 거래내역 기간 조회 구조
- 투자 현황: 전체·개인·AI별 자산·현금·손익·TWR·낙폭·보유·주문·거래내역
- AI 투자자: 생성, 최초 배정금, 추가 배정·회수, 판단 기록, 중지·재개, 장부 대조 상태
- 공통 상태: 로딩·빈 상태·오류·연결 끊김·지원 확인 전·장부 불일치
- 반응형: PC의 우측 상세 패널과 모바일의 전체 너비 상세 화면·하단 내비게이션

## 검토 방법

- 상단의 `프로토타입 상태`에서 정상, 시세 연결 끊김, 장 정보 실패, 주문 접수 확인 중, 장부 불일치 상태를 바꾼다.
- 종목 화면에서 관심·보유 탭, 종목 선택, 종목 추가, 순서 변경을 확인한다.
- 종목 상세에서 매수·매도, 가격·수량 입력, 주문 확인 흐름을 확인한다.
- 투자 현황에서 전체·개인·AI 투자자를 전환한다.
- AI 투자자 화면에서 중지·재개와 자금 배정 흐름을 확인한다.

## 범위 경계

- 차트·호가창·시장가 주문·외부 알림은 현재 요구사항의 후속 범위이므로 설계하지 않는다.
- API 지원 여부가 확인되지 않은 세션 주문과 비용·환율 값은 확정된 기능처럼 표현하지 않는다.
- AI 전략 기준·판단 주기 등 보류된 정책을 사용자가 입력하는 설정으로 임의 추가하지 않는다.
- 디자인 검토 중 확정된 제품 동작 변경은 `docs/REQUIREMENTS_AND_DESIGN.md`에 반영한 뒤 프로토타입과 동기화한다.
