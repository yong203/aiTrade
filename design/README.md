# aiTrade UI/UX 프로토타입

이 폴더는 전체 제품의 화면과 핵심 동작을 검토하는 클릭형 프로토타입을 관리한다. 현재 상태는 **전문 분야별 사용성 점검을 반영한 검토용 초안**이다.

- 기능 요구사항의 기준: [요구사항](../docs/REQUIREMENTS_AND_DESIGN.md)
- 프론트엔드 구현의 기준: 검토에서 확정한 화면 구조·상태·컴포넌트·표시 규칙
- 검토에서 제품 동작 변경에 합의하면 요구사항 문서와 [추적표](REQUIREMENTS_TRACE.md)를 함께 갱신한다.

## 실행

프로젝트 루트에서 실행한다.

```bash
python3 -m http.server 4173 --directory design
```

브라우저에서 `http://localhost:4173`을 연다.

- 모든 값과 동작은 검토용 예시다. 외부 API·실제 계좌·실제 주문과 연결되지 않는다.
- 모의 기준 시각은 **2026.09.22 10:32 KST**로 고정한다.
- 해외 시세 모의 환율: **1달러 = 1,350원**, **2026.09.22 10:30 KST**

## 포함 화면

| 화면 | 검토 범위 |
|---|---|
| 종목 | 국내·미국 장 상태, 관심·보유 목록, 종목 검색·추가·제거·순서 변경, 종목 상세, 지정가 주문 |
| 투자 현황 | 전체·개인별 자산·보유 투자 요약, 보유종목·손익·주문·거래, 모의 정정·취소, 기간·시장 조회 |
| AI 트레이더 | 트레이더·초안 선택, 생성·이름·투자 대상 수정, 자산 요약·TWR, 판단 기록·보유, 모의 자금 배정·회수, 중지·재개, 장부 대조 |
| 체결 알림 | PC 우측 메뉴·모바일 알림 패널의 최신순 모의 카드, 개인·AI 주문·거래 이동, 개별·전체 목록 지우기 |
| 공통 상태 | 로딩·빈 상태·오류·연결 끊김·지원 확인 전·장부 불일치 |
| 반응형 | PC 우측 상세 패널, 모바일 전체 너비 상세 화면·하단 내비게이션 |

## 현재 화면 동작

수치·토큰·컴포넌트 규격은 [디자인 시스템](DESIGN_SYSTEM.md), 변경 이력과 검증 결과는 [사용성 검토 기록](USABILITY_REVIEW.md)을 따른다.

### 공통 표시와 메뉴

- 영역은 배경색·간격으로 구분한다. 카드·표·앱 셸·버튼·입력·배지·대화상자의 장식 테두리와 구분선은 제거했다.
- 입력·보조 버튼의 면과 hover 배경, 키보드 포커스·차트·판단 기록·아이콘의 선은 유지한다. 오류는 붉은 배경과 문구로 표시한다.
- 짙은 중립 표면과 Pretendard를 사용한다. 상태 문구는 흰색·회색, 배지 배경은 낮은 채도로 표시한다. 민트색은 주요 행동·AI 선택 표시에 사용한다.
- 화면 제목 주변의 반복 설명과 영문 레이블을 줄였다. 프로토타입 상태 선택기는 앱 상단에 통합했다.
- aiTrade 로고는 PC·모바일 상단에만 표시한다. 메뉴 아이콘은 Lucide SVG 시세 차트·자산 구성·AI 로봇을 공통 사용한다.
- PC 메뉴 안쪽 상단 버튼을 누르면 메뉴를 접거나 펼친다. 메뉴 폭이 바뀌어도 로고·접기 버튼의 위치는 유지한다.
- PC 메뉴를 접으면 아이콘 메뉴를 사용하고 AI 트레이더 목록은 왼쪽에 연다. 모바일에서는 하단 AI 트레이더 메뉴로 목록을 연다.
- PC 우측 메뉴의 메뉴 버튼들 아래부터 하단 개인 프로필 위까지 남은 세로 공간을 체결 알림 영역으로 사용한다.
- PC 메뉴가 접혀 있으면 AI 아이콘과 알림 아이콘 사이에 구분선을 표시한다. 알림 아이콘은 AI 아이콘 바로 아래 구분선 다음에 둔다.
- 접힌 PC 메뉴의 알림 아이콘을 누르면 메뉴를 펼친다. 기존 알림 영역은 제자리에 즉시 표시한다.
- 개인 프로필은 메뉴 하단에 유지한다.
- PC 창에 메뉴·프로필·알림 카드 한 개를 함께 표시할 수 있으면 알림 목록만 내부 스크롤한다.
- PC 창이 너무 낮아 메뉴·프로필·알림 카드 한 개를 함께 표시할 수 없으면 우측 메뉴 전체를 스크롤해 모든 영역에 접근한다.
- 알림 개수가 바뀌어도 상단 내비게이션 위치는 유지한다.
- 모바일 하단 네 번째 알림 메뉴는 PC와 같은 체결 목록을 대화상자 패널로 연다.
- 접힌 PC 목록·모바일 선택 패널에서 바깥 클릭 또는 Escape를 입력하면 목록을 닫는다.
- AI 화살표는 같은 중앙 위치에서 회전한다. 메뉴 폭과 PC AI 목록은 160ms 동안 전환한다.
- 새로고침·페이지 전환 시 앱 셸과 콘텐츠를 제자리에 즉시 표시한다. 진입 애니메이션·강제 부드러운 스크롤은 사용하지 않는다.

### 종목과 주문

- 종목 검색은 결과 수·로딩·빈 상태·오류와 관계없이 같은 크기를 유지한다. 결과 영역만 스크롤한다.
- 검색에서 종목을 추가하고 닫으면 관심 목록·개수가 즉시 갱신된다.
- 종목 목록에는 연결 끊김을 표시하고 상세에는 실제 수신 시각도 표시한다. 수신 상태 열·반복 수신 시각·조회 주기·지연 시간 문구는 제거했다.
- 관심·보유 탭을 선택하면 상세를 닫고 목록만 표시한다. 목록에서 종목을 직접 선택하면 상세를 연다.
- 종목 행 전체 클릭·Enter·Space로 상세를 연다. 행 끝 화살표는 안내 장식으로 유지한다.
- 상단 거래시간 외 표시는 글자·배경·상태 점을 회색으로 낮춰 비활성 상태를 구분한다.
- PC·모바일 상세에 닫기 버튼을 제공한다. 주문 화면에는 보유수량·평균매입가·가격·수량·예상 주문금액을 표시하고, 비용·손익은 투자 현황의 손익 탭에 둔다.
- 관심종목 순서 변경 대화상자에서는 드래그로 임시 순서를 편집한다. 잡은 행은 반투명하게 표시하고 목록의 보이는 영역 안에서 위아래로만 이동한다. 들어갈 자리는 점선 없이 민트색으로 표시한다.
- 순서 변경을 저장하면 목록에 반영한다. 취소하면 원래 순서를 유지한다. 항목은 휴지통 아이콘 버튼으로 제거한다.
- 주문 정정 시 선택한 주문의 미체결 가격·잔여수량을 입력하고 변경 전후를 확인한 뒤 목록에 모의 결과를 반영한다.
- 정정 확인에서 돌아가면 입력값을 유지한다. 취소하면 목록을 유지한다. 주문 취소는 대상 확인까지 제공한다.
- 실제 주문·정정·취소는 API 확인 전이다. 모든 주문 버튼은 모의 흐름이다.

### 금액과 투자 현황

- 가격·등락금액·평균매입가·평가금액·손익·주문·거래·알림의 금액은 숫자 오른쪽에 `원`을 표시한다.
- 해외 시세는 모의 환율을 적용하고 계산 후 표시 단계에서 반올림한다. 등락률은 원래 시세 기준을 유지한다. 이미 원화인 요약·세금·수수료는 그대로 사용한다.
- 해외 주문·정정은 원 단위 정수 입력으로 시연한다. 원래 USD 주문가격을 보존하고 원화 정정값을 별도로 저장한다. 실제 USD 변환·호가단위 검증은 API 확인 필요다.
- 거래 기록에는 기록별 모의 환율을 저장한다. 환율이 없으면 `확인 불가`로 표시한다.
- 전체·개인 투자 현황과 AI 상세는 같은 여섯 지표를 표시한다: 총 자산·미투자 현금·투자금·보유 평가액·평가 순손익·보유 수익률.
- 전체·개인과 기존·초안 AI 자산 요약은 같은 카드 컴포넌트·그리드와 콘텐츠 폭·높이·여백·배경·반응형 배치를 사용한다. 긴 금액은 생략하지 않고 줄바꿈한다.
- 투자 주체를 전환하면 여섯 지표와 손익·보유·주문·거래 예시를 함께 전환한다. 보유 표는 일부 fixture이며 자산 요약과 합계가 다르다.
- 보유종목·손익·주문·거래 탭은 같은 구조를 사용한다. 실현손익은 손익 탭에서 분리한다.
- 전체·개인 선택도 같은 탭 스타일과 160ms 회색 선택 배경 이동을 사용한다. 투자 주체 변경 시 하위 계좌 내역 탭의 배경은 즉시 표시한다.
- 수동 매도는 클릭한 종목과 투자 주체로 이어진다.

### AI 트레이더

- 기존 트레이더·생성 초안은 같은 상세 구조를 사용한다. 초안은 초기 현금과 빈 성과·판단 기록·보유 상태를 표시한다.
- 선택 상태·현금·판단 기록·보유분은 트레이더별로 분리한다.
- AI 상세·초안의 여섯 수치 카드는 상세 소개 영역 바깥에 두어 투자 현황과 같은 콘텐츠 폭을 사용한다.
- 이름을 수정하면 목록·상세·투자 현황·주문·거래·체결 알림의 표시 이름을 갱신한다. 트레이더별 식별자·금액·기록은 유지한다.
- 생성 화면에서는 이름·유형·배정금·종목 선정 방식·투자 대상을 함께 입력하고 생성 시 검증한다.
- 기본 `종목 선택하지 않음`은 AI가 허용 투자범위에서 판단마다 후보를 선정하는 방식이다.
- `직접 선택`에서는 검색·개인 관심종목으로 추가한 종목을 투자 대상으로 저장한다. 최소 1개를 선택해야 하며 중복 추가는 차단한다.
- 선택 가능 범위는 국내 주식·ETF다. 미국은 후속 지원을 안내한다. 선정 방식·선택 목록은 트레이더별로 모의 저장해 상세에 표시하고 개인 관심목록은 유지한다.
- 기존 트레이더·초안의 투자 대상을 수정할 때는 현재 설정으로 시작한다. 저장하면 해당 트레이더의 선정 방식·종목 목록만 갱신한다. 취소·닫기는 기존 설정을 유지한다.
- 투자 대상 수정에도 생성과 같은 최소 1개·중복 방지·지원 범위 검사를 적용한다. 이름·투자 유형·자금·보유·주문은 유지한다.
- 최초 배정은 개인 사용 가능 현금 한도 안에서 진행한다. 운용 전·중지 완료 후에는 추가 배정·회수를 모의 이동한다.
- 트레이더별 TWR 그래프에서 커서·탭·키보드로 모의 평가 시각·수익률을 확인한다. 최초 배정 전 날짜·임의 누락일은 표시하지 않는다.

### 판단 기록과 거래내역

- 판단 제목 옆에 매수·매도·기타와 종목명 배지를 표시한다. 복수 보유 점검은 종목별, 운영 기록은 운영 범위로 구분한다.
- 분류·종목은 구조화된 모의 기록에서 가져온다. 모바일에서는 날짜를 본문 위에 둔다.
- 최신 판단 기록의 점은 민트색, 다음 점까지의 선은 기존 중립색으로 점차 옅어지게 표시한다. 나머지 점·선은 기존 색을 유지한다.
- 판단 기록·거래내역은 내부 스크롤을 사용한다. 하단 손잡이·키보드로 높이를 조절한다.
- 판단 기록은 내부 스크롤 하단에 도달하면 과거 모의 기록 10건을 기존 목록 뒤에 추가한다. 최신순을 유지하며 기간 검색은 제공하지 않는다.
- 거래내역은 내부 스크롤 하단에 도달하면 과거 모의 기록 10건을 기존 목록 뒤에 추가하며 읽던 위치를 유지한다.
- 첫 표시·높이 확장·화면 복원·기간/시장 조회 초기화 후 스크롤이 없고 다음 거래내역이 있으면 10건씩 추가한다. 세로 스크롤이 생기거나 기록 끝에 도달하면 자동 추가를 멈춘다.
- 판단 기록은 트레이더별, 거래내역은 전체·개인·AI·초안별로 높이·불러온 수·읽던 위치를 유지한다.
- 거래내역의 기간·시장 조회를 적용하면 목록 추가 범위·스크롤을 초기화하고 높이는 유지한다. 빈 결과도 같은 높이 조절 구조를 사용한다.
- 높이 조절 드래그 중 화면 가장자리에 포인터를 유지하면 페이지도 스크롤한다. 최소·최대 높이에서 멈추며, 취소하면 원래 높이·페이지 위치로 돌아간다.

### 체결 알림

- 알림은 실제 체결 결과를 표시하는 모의 카드로 시연한다. 실제 체결 API와 연결되지 않는다.
- 카드의 세로 여백을 줄이고 첫 줄은 개인·AI 이름 왼쪽·체결시각 오른쪽으로 배치한다.
- 둘째 줄은 종목·매수/매도를 왼쪽에, `체결수량 / 원화 주당 체결가격`을 오른쪽 그룹으로 표시한다. 가격은 상단 체결시각과 같은 오른쪽 여백·끝선에 정렬한다. 긴 내용은 정보를 생략하지 않고 줄바꿈한다.
- 각 줄 안에서 글자 크기·텍스트 기준선을 맞춘다. 체결시각은 오른쪽에 정렬하고 모서리의 개별 X 조작 영역과 겹치지 않게 한다.
- 주당 체결가격의 의미는 카드의 접근 가능한 이름·가격 툴팁에도 유지한다.
- 목록은 최신순이며 최근 5개로 제한하지 않는다. 카드가 많으면 목록 안에서 스크롤한다.
- 상단 알림 벨·기존 알림창, 접수·거부 알림, 읽음 처리·미읽음 개수, 알림 전용 페이지는 제공하지 않는다.
- 접힌 PC·모바일 알림 아이콘의 오른쪽 위에 붉은 원형 배지와 흰 숫자로 현재 목록에 남은 카드 수를 표시한다.
- 숫자 배지는 0개면 숨기고 1~99개는 해당 숫자, 100개 이상은 조금 넓힌 둥근 배지에 `99+`를 표시한다. 버튼의 접근 가능한 이름·툴팁에는 정확한 전체 카드 수를 표시한다.
- 개인 카드는 개인 투자 현황의 `주문·거래`를, AI 카드는 해당 AI 상세의 `주문·거래`를 연다.
- 카드의 작은 원형 X는 hover·키보드 포커스 표시 때 보이고 터치에서는 항상 표시한다. SVG X는 원 중앙에 정렬한다.
- 마우스 개별 삭제 후에는 다른 카드로 포커스를 자동 이동하지 않고 포인터가 카드를 벗어나면 X를 숨긴다.
- 키보드 개별 삭제 후에는 남은 이웃 카드로 포커스를 이어간다.
- 개별 X의 원 중심은 카드 우측 상단 모서리에 두고 원이 반쯤 걸치도록 표시한다.
- 목록 위·오른쪽 여백과 카드 사이 간격을 확보해 원·포커스·조작 영역이 잘리거나 앞 카드의 텍스트와 겹치지 않게 한다.
- 모바일 알림 패널의 개별 X 조작 영역은 44px로 유지하며 보이는 원의 크기는 늘리지 않는다.
- 제목 오른쪽에는 한글 `전체 지우기` 텍스트 버튼을 둔다. 개별 X와 전체 지우기는 옅은 빨강으로 표시한다.
- 삭제는 알림 목록만 바꾸고 주문·거래 기록은 유지한다. 전체 지우기 도중 도착한 새 알림은 유지한다.
- 지운 알림은 화면 전환·재렌더에 복원하지 않는다. 삭제 상태는 세션에서 유지하며 새로고침하면 초기 모의 목록으로 돌아간다.
- 모바일 패널은 바깥 클릭·Escape로 닫고 하단 알림 메뉴로 포커스를 돌려준다.
- 모바일 목록도 화면 높이와 패널 여백에 맞춘 최대 높이를 사용하고 목록 안에서 스크롤한다.
- 주문·거래내역은 주문 단위 기록을 유지한다. 모의 체결 카드가 개별 체결 이벤트 로그 수집을 뜻하지 않는다.

### 전환 효과

| 대상·조건 | 효과 |
|---|---|
| 검색·순서 변경·주문 정정·확인·AI 생성·투자 대상 수정·이름 수정·자금 관리 대화상자 열기·닫기 | 창과 배경 어두움·흐림을 140ms 전환 |
| 모바일 AI 목록 열기·닫기 | 짧은 전환 |
| 종목 상세 열기·닫기 | 180ms 작은 이동·투명도 전환, PC 목록 폭·세로 배치 상세 높이 함께 전환 |
| 관심·보유, 전체·개인 및 계좌 내역 탭 선택 | 회색 선택 배경을 새 위치·폭으로 160ms 이동; 연속 선택·모바일·글꼴·너비 변경에 대응 |
| 새 체결 카드 첫 표시 | 오른쪽에서 260ms 진입; 화면 전환·재렌더·목록 재개방에 반복하지 않음 |
| 체결 카드 개별 삭제 | 해당 카드만 왼쪽으로 220ms 이동 후 제거 |
| 체결 카드 전체 지우기 | 아래의 오래된 카드부터 왼쪽 220ms 삭제; 기본 70ms 간격, 카드가 많으면 최대 시작 지연 420ms 안에서 모두 순차 출발하도록 간격 축소 |
| 화면 진입·트레이더 변경 후 TWR 차트가 보이기 시작할 때 | 선·민트 채움이 0% 기준선에서 580ms 상승; 축·기록값 유지 |

- 주문 종류를 변경할 때는 종목 상세 진입 효과를 반복하지 않는다.
- 투자 주체 변경 시 하위 계좌 내역 탭의 선택 배경은 즉시 표시한다.
- 같은 TWR 차트에서 탭을 전환할 때는 상승 효과를 반복하지 않는다. 시점 탐색 시 최종 형태를 즉시 표시한다.
- 동작 줄이기 설정에서는 위 전환을 즉시 처리한다.
- 모바일 상세·알림의 닫기·포커스 동작, 접힌 메뉴의 접근 가능한 이름, 키보드 순서 변경 안내를 제공한다.

## 검토 방법

### 공통·종목·주문

- 상단 `PREVIEW` 선택기에서 정상·시세 연결 끊김·장 정보 실패·주문 접수 확인 중·장부 불일치 상태를 확인한다.
- 종목 화면에서 관심·보유 탭, 종목 선택·추가·순서 변경을 확인한다.
- 종목 행의 이름·가격·화살표 영역 클릭과 Enter·Space가 같은 상세를 여는지 확인한다. 화살표에 별도 버튼 포커스가 없는지 확인한다.
- 상단 거래시간 외가 회색 비활성 표시이며 장 정보 조회 실패와 구분되는지 확인한다.
- 상세에서 매수·매도, 가격·수량 입력, 주문 확인 흐름을 확인한다.
- PC 메뉴를 접고 펼친 뒤 AI 목록 선택·닫기와 화살표 중앙 정렬을 확인한다.
- 투자 현황에서 전체·개인을 전환한다. PC 우측·모바일 하단 AI 메뉴에서 트레이더·초안 선택과 추가를 확인한다.
- 전체·개인 선택의 스타일·배경 이동이 보유종목·손익·주문·거래 탭과 같은지 확인한다. 주체 변경 시 하위 탭 배경은 즉시 표시되는지 확인한다.
- 보유종목에서 평균매입가·평가손익·수익률을, 주문·거래에서 정정·취소를 확인한다.

### AI 생성·수정

- 생성 화면에서 이름·유형·배정금·투자 대상을 입력한다. 선정 방식을 전환하고 검색·개인 관심종목으로 여러 국내 종목을 추가·제거한다.
- 생성 시 기본정보 오류·사용 가능 현금 초과·직접 선택 0개를 차단하는지 확인한다. 중복 종목 추가도 차단하는지 확인한다.
- 선정 방식 전환 시 기본정보·선택 목록이 유지되는지 확인한다. 닫기·취소 후 재개방 시 초기화되는지 확인한다.
- 생성 후 상세의 선정 방식·대상 표시와 개인 관심목록 유지를 확인한다.
- 기존 트레이더·초안의 투자 대상 수정창을 열어 현재 설정 표시와 선정 방식 전환 중 임시 선택 유지를 확인한다.
- 수정 저장 시 직접 선택 0개 차단, AI 선정의 빈 직접 선택 목록 저장, 해당 트레이더의 투자 대상만 갱신되는지 확인한다.
- 수정 취소·닫기 후 재개방 시 기존 설정이 표시되는지 확인한다. 이름·유형·배정금·현금·보유·주문·개인 관심목록 유지도 확인한다.
- 기존 트레이더·초안의 이름 수정, TWR 시점별 값, 중지·재개·자금 배정을 확인한다.

### 기록 높이·이어보기

- 판단 기록·거래내역의 손잡이를 드래그하거나 위·아래 화살표와 Home·End로 높이를 바꾼다.
- 판단 기록은 내부 스크롤 하단에서 과거 10건이 이어지고 읽던 위치가 유지되는지 확인한다.
- 거래내역은 내부 스크롤 하단에서 과거 10건이 이어지고 읽던 위치가 유지되는지 확인한다.
- 다른 트레이더나 전체·개인·AI·초안 화면으로 갔다 돌아왔을 때 높이·불러온 수·읽던 위치 유지를 확인한다.
- 거래내역 기간·시장 조회 후 목록·스크롤 초기화와 높이 유지를 확인한다.
- 거래내역 빈 결과·새 초안 판단 기록에도 손잡이와 빈 상태가 표시되는지 확인한다.

### 체결 알림

- PC 우측 메뉴의 메뉴 버튼들 아래부터 하단 개인 프로필 위까지 남은 세로 공간에 체결 카드가 최신순으로 표시되는지 확인한다. 5개보다 많은 알림도 확인한다.
- 메뉴·프로필·알림 카드 한 개가 함께 들어가는 PC 창에서는 목록 내부 스크롤을 확인한다. 함께 들어가지 않는 매우 낮은 PC 창에서는 우측 메뉴 전체 스크롤로 모든 영역에 접근하는지 확인한다.
- 알림 추가·삭제·전체 지우기 동안 상단 내비게이션 위치가 유지되는지 확인한다.
- 첫 줄의 개인·AI 이름 왼쪽·체결시각 오른쪽 배치와 둘째 줄의 종목·매수/매도 왼쪽·`체결수량 / 원화 주당 체결가격` 오른쪽 그룹 배치를 확인한다. PC·모바일에서 가격과 시간의 오른쪽 끝선 정렬, 긴 내용의 줄바꿈과 주당 의미의 접근 가능한 이름·가격 툴팁도 확인한다.
- 같은 줄 안의 글자 크기·텍스트 기준선과 시간 오른쪽 정렬·모서리 X 영역 분리를 확인한다.
- 개인 카드·AI 카드를 선택해 해당 주체의 `주문·거래`로 이동하는지 확인한다. AI 이름 수정 후 표시 이름과 이동 대상을 확인한다.
- 옅은 빨강의 작은 원·중앙 SVG X와 hover·키보드 포커스 표시를 확인한다. 모바일 알림 패널의 상시 표시·44px 개별 X 조작 영역에서도 보이는 원의 크기가 유지되는지 확인한다.
- 마우스 개별 삭제 후 포인터를 카드 밖으로 옮겨 X가 숨겨지는지 확인한다. 키보드 개별 삭제 후에는 남은 이웃 카드로 포커스가 이어지는지 확인한다.
- 카드 우측 상단 모서리에 원이 반쯤 걸치는지 확인한다. 목록의 첫 카드·오른쪽 경계·인접 카드에서도 원·포커스·조작 영역이 잘리거나 앞 카드의 텍스트와 겹치지 않는지 확인한다.
- 삭제 후 화면 전환·재렌더에 알림이 복원되지 않고 기록은 유지되는지 확인한다.
- 제목 오른쪽의 옅은 빨강 한글 `전체 지우기` 텍스트 버튼과 아래부터 순차 삭제를 확인한다. 삭제 도중 새 모의 체결 카드가 추가되면 유지되는지 확인한다.
- 상단 `PREVIEW`의 `새 체결 알림`을 선택할 때마다 개인·중기·장기 모의 체결을 순환 추가한다. 새 카드 진입과 전체 지우기 도중 도착한 카드 유지를 이 제어로 확인한다.
- PC 메뉴를 접고 AI 아이콘 바로 아래 구분선 다음의 알림 아이콘으로 메뉴를 펼친다. 기존 알림 영역이 위로 움직이는 전환 없이 제자리에 표시되고 카드 진입 효과를 반복하지 않는지 확인한다.
- 모바일 네 번째 알림 메뉴에서 같은 카드 배치·목록·바깥 클릭·Escape·닫힌 뒤 포커스 복귀를 확인한다.
- 새 카드 진입 효과가 한 번만 실행되는지 확인한다. 동작 줄이기 설정에서 진입·삭제가 즉시 끝나는지 확인한다.

## 범위와 확인 상태

- 포함: AI별 TWR 추이 그래프
- 후속 범위: 종목 가격 차트·호가창·시장가 주문·외부 알림·미국 자동매매
- API 확인 필요: 지원 여부가 확인되지 않은 세션 주문, 비용·환율 값, 실제 USD 변환·호가단위 검증
- 보류: AI 전략 기준·판단 주기, 운영 중 투자 대상 변경 적용 시점, 기존 보유종목·미체결 주문 처리 정책
- 제품 구현 전: 백엔드 설정 저장·허용 투자범위 적용·판단 후보 선정
- 화면 검토용 fixture: 비용·수익률·AI 성과 그래프, 일부 보유 내역, 체결 알림
- 실제 체결 알림 API 연결·수집 단위·중복 구분은 제품 구현 전이다. 주문·거래의 주문 단위 기록 계약을 유지한다.
- 보류 정책을 사용자 입력 설정으로 임의 추가하지 않는다. API 확인 필요 항목은 확인 상태를 표시한다.
- 판단 기록·거래내역 이어보기는 외부 API를 호출하지 않는 모의 시연이다.
- 판단 기록 제품 구현 시 커서 조회·중복 제거·마지막 페이지 확인을 연결한다.
- 거래내역 제품 구현 시 기간·시장 조건의 페이지 조회·중복 제거·종료 신호를 연결한다.
- 제품 동작 변경이 확정되면 `docs/REQUIREMENTS_AND_DESIGN.md`에 반영한 뒤 프로토타입과 동기화한다.
