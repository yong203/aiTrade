# 요구사항 추적

프로토타입의 화면과 상태가 `docs/REQUIREMENTS_AND_DESIGN.md`의 어떤 요구사항을 검토하는지 연결한다.

| 요구사항 영역 | 프로토타입 위치 | 포함 상태·동작 | 상태 |
|---|---|---|---|
| 이름 검색과 추가 | 종목 → 종목 추가 | 검색, 등록됨, 추가 성공, 결과 없음, 오류·재시도 | 확정 |
| 관심종목 관리 | 종목 → 관심 | 제거, 순서 변경, 목록 유지 안내 | 확정 |
| 실시간 시세 | 종목 목록·상세 | 현재가, 등락, 실시간, 주기 조회, 지연, 연결 끊김 | 확정 / 주기 API 확인 필요 |
| 장 상태와 시간 | 종목 상단 | 국내·미국 세션, KST, 다음 세션, 조회 실패 | 확정 / 세션 API 확인 필요 |
| 보유 목록과 상세 | 종목 → 보유·상세 | PC 우측 패널, 모바일 전체 화면 | 확정 |
| 지정가 주문 | 종목 상세 | 매수·매도, 가격·수량, 예상 주문금액, 확인 | 확정 / 세션 지원 API 확인 필요 |
| 주문 전 종목 전환 | 종목 상세 | 입력 초기화 확인 | 확정 |
| 주문 접수 확인 | 주문 확인·주문 목록 | 전송 중, 접수, 접수 확인 중, 중복 제출 방지 | 확정 |
| 정정·취소 | 주문 화면 | 잔여수량 기준 진입점과 확인 | 확정 / 허용 항목 API 확인 필요 |
| 거래내역 | 주문·거래 → 거래내역 | 최근 1개월, 기간 선택, 더 보기, 주문 단위 집계 | 확정 |
| 앱 내부 알림 | 상단 알림 | 접수, 부분체결, 전체체결, 거부 | 확정 |
| 투자 현황 | 투자 현황 | 전체·개인·AI, 자산·현금·손익·TWR·보유·주문·거래 | 확정 |
| 비용 표시 | 투자 현황·종목 상세 | 비용 전, 세금, 수수료, 비용 합계, 순손익, 예상·확인 불가 | 확정 / 산식 API 확인 필요 |
| AI 투자자 생성 | AI 투자자 → 추가 | 이름, 초단타·중기·장기, 최초 배정금 | 확정 |
| AI 자금 이동 | AI 투자자 | 추가 배정·회수, 사용 가능 현금, 중지 완료 조건 | 확정 |
| AI 판단 기록 | AI 투자자 → 판단 기록 | 후보·행동·근거·주문 결과 연결 | 확정 / 전략 기준 보류 |
| AI 중지·재개 | AI 투자자 | 확인, 중지 처리 중, 중지 완료, 대조 후 재개 | 확정 |
| 장부 불일치 | 전역 배너·AI 투자자 | 신규 자동 주문 차단, 재대조 | 확정 |
| 판단 주기·조건 | AI 투자자 안내 | 구체 설정을 제공하지 않고 보류 표시 | 보류 |
| 환율·예상 비용 | 투자 현황 보조 정보 | 적용 기준 시각·예상·확인 불가 표기 | API 확인 필요 |

## 프로토타입 전용 제어

상단의 `프로토타입 상태` 선택기는 제품 기능이 아니다. 화면별 예외 상태를 한 프로토타입에서 검토하기 위한 도구이며 React 제품 구현 시 개발·테스트 환경의 fixture 또는 Storybook 시나리오로 대체한다.
