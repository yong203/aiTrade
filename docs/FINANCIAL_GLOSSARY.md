# 금융 용어

요구사항과 대화에서 사용하는 용어를 정리한다. 프로젝트의 확정·미정 사항은 [요구사항](REQUIREMENTS_AND_DESIGN.md)을 기준으로 한다.

## 상품·시세·시장

| 용어 | 뜻과 프로젝트 기준 |
|---|---|
| 주식 | 회사의 소유 지분을 나타내는 증권. [주식의 기본 개념](https://www.investor.gov/introduction-investing/investing-basics/investment-products/stocks) |
| ETF(상장지수펀드) | 거래소에 상장되어 주식처럼 매매하는 펀드. 지수·자산 등을 추종하는 상품 등이 있다. [한국거래소 설명](https://open.krx.co.kr/contents/OPN/01/01030100/OPN01030100.jsp) |
| 종목 | 검색·시세 조회·매매의 대상이 되는 개별 주식이나 ETF. |
| 종목코드·티커 | 종목을 식별하는 코드. 국내 종목코드와 미국 티커를 사용하며, 시장 정보도 함께 구분한다. |
| 시장 | 종목이 거래되는 시장. 프로젝트에서는 국내와 미국을 구분해 시세·장 상태·주문 지원을 확인한다. |
| 거래 통화 | 실제 시장 거래와 주문·체결에 사용하는 통화. 국내는 원화(KRW), 미국은 달러(USD)를 사용한다. 앱의 금액 표시 통화인 원화와 구분하며 원통화 금액은 내부에 보존한다. |
| 표시 통화 | 앱 화면에서 금액을 나타내는 통화. 모든 가격·평가액·손익·비용·현금·주문·거래 금액은 원 단위(KRW)로 표시한다. 해외 금액은 적용 환율로 환산한다. 해외 주문·정정 가격의 기본 입력 통화도 원화이며, 실제 거래 통화로의 변환과 구분한다. |
| 관심종목 | 사용자가 관찰하려고 등록한 종목. 실제 보유 여부와 독립적이다. |
| 보유종목·보유수량 | 실제 소유한 종목과 그 수량. 앱에서는 개인·각 AI별 귀속을 구분한다. |
| 현재가 | 최신 제공 가격. 실제 주문의 체결가격은 체결 결과로 확인한다. |
| 전일 종가 | 직전 거래일에 장이 끝날 때의 가격. 이 프로젝트의 등락 기준은 직전 거래일 **정규장** 종가다. |
| 등락 금액 | 현재가에서 등락 기준 가격을 뺀 금액. 해외 종목은 두 가격에 같은 비교 시점의 환율을 적용해 원화로 표시한다. 매입가 대비 투자손익과 구분한다. |
| 등락률 | 등락 금액을 기준 가격으로 나눈 비율. 기존 시장 가격 기준의 전일 대비 변화율을 유지하며, 환율 변화에 따른 투자성과와 구분한다. |
| 거래량 | 일정 기간에 거래된 수량. |
| 호가 | 매수·매도하려는 가격 제시. 호가창은 가격별 주문 수량 등을 보여주는 화면이다. |
| 캔들·일봉 | 일정 시간의 시가·고가·저가·종가를 묶어 표시한 가격 기록. 일봉은 하루 단위 기록이다. |
| OHLCV | 시가(Open)·고가(High)·저가(Low)·종가(Close)·거래량(Volume). AI의 초기 가격·거래량 입력에 사용한다. |
| 거래일 | 해당 시장에서 거래가 진행되는 날짜. 한국시간 자정과 일치한다고 가정하지 않는다. |
| 정규장·시간외·세션 | 정규장은 시장의 기본 거래시간, 시간외는 그 밖의 거래 구간, 세션은 구분된 거래 구간이다. 시세 제공과 주문 지원 여부는 각각 확인한다. |
| 휴장·거래시간 외 | 휴장은 시장이 열리지 않는 날, 거래시간 외는 현재 거래 세션이 진행되지 않는 상태. 정보 조회 실패와 구분한다. |

가격·시장 데이터 항목은 [토스 공식 API 명세](https://openapi.tossinvest.com/openapi-docs/latest/openapi.json)를 참고한다.

## 주문·체결

주문 유형의 기본 개념은 [Investor.gov 설명](https://www.investor.gov/introduction-investing/investing-basics/how-stock-markets-work/types-orders), 접수·체결 상태는 [토스 공식 API 명세](https://openapi.tossinvest.com/openapi-docs/latest/openapi.json)를 참고한다.

| 용어 | 뜻과 프로젝트 기준 |
|---|---|
| 매수·매도 | 매수는 종목을 사는 것, 매도는 보유분을 파는 것. |
| 주문 | 증권사에 매수·매도를 요청하는 것. 거래 완료는 실제 체결로 확인한다. |
| 지정가 주문 | 매수 시 지정한 가격 이하, 매도 시 지정한 가격 이상에서 체결되도록 요청하는 주문. 체결되지 않을 수 있다. 초기 수동매매 방식이다. |
| 시장가 주문 | 체결가격을 지정하지 않고 현재 가능한 가격으로 거래를 요청하는 주문. 초기 수동매매에서는 후속 범위다. |
| 주문가격·주문수량·주문금액 | 요청한 가격·수량과 그에 따른 금액. 실제 체결가격·수량·금액과 구분한다. |
| 접수 | 증권사가 주문을 받아들인 상태. 체결과 구분한다. |
| 접수 확인 중 | 응답 단절 등으로 접수 여부가 불명확한 상태. 조회로 확인하며 같은 주문을 자동 재제출하지 않는다. |
| 체결 | 주문이 실제 거래로 성립한 것. 보유·현금·거래내역은 실제 체결분에 따라 반영한다. |
| 미체결·부분체결 | 미체결은 아직 거래되지 않은 수량, 부분체결은 주문 수량 중 일부만 거래된 상태. |
| 평균 체결가격 | 한 주문이 여러 가격에 체결됐을 때, 체결금액을 체결수량으로 나눈 가격. 보유분의 평균매입가와 구분한다. |
| 정정·취소·거절 | 정정은 주문 조건 변경, 취소는 미체결 잔여분 철회, 거절은 요청이 받아들여지지 않은 것. 취소 요청 후 종료 여부를 확인한다. |
| 청산 | 보유분을 매도해 포지션을 종료하는 것. AI 트레이더 중지 시에는 미체결 자동 주문을 취소하고 보유분을 유지한다. |

주문·정정 가격의 표시와 입력 기준은 다음과 같다.

- 화면의 가격·금액과 주문·정정 가격 입력은 원화 기준이며 원통화 값은 보존한다.
- 실제 USD 가격 역환산·환율 적용 시점·호가단위·반올림 검증은 API 확인이 필요하다.
- 모의 원화 정정은 별도 요청가격을 기록하는 UI 시연이다.

## 매입원가·손익·비용

평균원가·선입선출의 기본 개념은 [Fidelity 설명](https://www.fidelity.com/tax-information/tax-topics/capital-gains-cost-basis)을 참고한다. 아래 비용 배분은 이 프로젝트의 투자 주체별 장부 기준이다.

| 용어 | 뜻과 프로젝트 기준 |
|---|---|
| 매입원가 | 보유분을 매수한 금액. 앱의 비용 반영 전 원가에는 세금·수수료를 포함하지 않고 별도 관리한다. |
| 평균매입가·이동평균 | 현재 보유분의 원가를 수량으로 나눈 주당 가격. 추가 매수 때 남은 보유분과 새 매수분으로 갱신한다. 개인·각 AI별로 계산하며, 차트의 주가 이동평균선과 구분한다. |
| 주가 이동평균선 | 일정 기간의 주가를 평균한 값을 이어 표시한 차트 지표. 초기 전략에 사용할 지표는 미정이다. |
| 선입선출(FIFO) | 먼저 매수한 수량부터 매도된 것으로 원가를 계산하는 방식. 앱 장부의 원가 계산에는 이동평균을 사용한다. |
| 평가금액 | 현재 보유수량을 현재 가격으로 평가한 금액. 현금 잔액과 구분한다. |
| 투자금·보유 평가액 | 화면의 투자금은 현재 보유 종목의 비용 반영 전 매입원가다. 보유 평가액은 현재 보유수량의 시가 평가액이다. |
| 미투자 현금·총 자산 | 미투자 현금은 투자 주체의 현금 잔액으로 주문에 묶인 현금도 포함한다. 총 자산은 이 현금과 보유 평가액의 합이다. |
| 실현손익 | 실제 매도 체결로 확정된 손익. 미체결 주문은 포함하지 않는다. |
| 평가손익 | 현재 보유분의 평가금액과 남은 매입원가에 따른 손익. 가격이 변하면 달라진다. |
| 총손익 | 같은 통화·비용 반영 기준의 누적 실현손익과 현재 보유분 평가손익을 합한 금액. |
| 비용 반영 전 손익 | 거래가격·원가 차이로 계산한 손익. 세금·수수료를 차감하기 전 금액이다. |
| 세금·수수료·비용 합계 | 거래 비용의 세금과 증권사 수수료는 각각 표시한다. 비용 합계는 두 금액의 합이다. API의 거래 세금과 별도 신고·납부 세금은 구분한다. |
| 별도 신고·납부 세금 | 거래별 비용과 별도로 신고·납부하는 세금. 국외주식 양도소득세처럼 별도 신고가 필요한 세금도 있다. 앱에서 계산할 범위는 미정이다. [국세청 안내](https://www.nts.go.kr/nts/na/ntt/selectNttInfo.do?bbsId=1028&mi=2201&nttSn=1353905) |
| 순손익 | 해당 손익에 귀속된 거래 세금·수수료를 반영한 금액. 별도 신고·납부 세금의 계산 범위는 미정이다. |
| 비용 배분 | 이미 발생한 매수 비용을 매도 수량 비율에 따라 실현손익과 남은 보유분의 평가손익으로 나누는 것. 배분 자체로 현금을 다시 차감하지 않는다. |
| 예상 매도 비용 | 현재가로 남은 보유분 전부를 매도한다고 가정한 세금·수수료. ‘예상’으로 표시하며, 현금에서 실제 차감하지 않는다. |
| 보유 수익률 | 현재 보유분의 비용 반영 후 평가 순손익을 투자금(매입원가)으로 나눈 비율. 현금·실현손익은 계산 범위에서 제외한다. |
| 원화 환산 | 달러 금액에 적용 환율(1달러당 원화 금액)을 곱해 화면 표시·성과 계산용 원화 금액을 구하는 것. 해외 가격·등락 금액·평균매입가·평가액·손익·주문·거래 등 모든 화면 금액과 AI TWR 계산에 사용한다. 원통화 금액과 적용 환율·기준 시각을 내부에 보존하며 실제 환전은 실행하지 않는다. |
| 적용 환율·환율 기준 시각 | 금액 환산에 사용한 환율과 그 환율이 가리키는 시각. 시세 가격을 비교할 때는 같은 비교 시점의 환율을 사용한다. 현재 자산·보유 요약에는 같은 평가 시점의 환율을 사용한다. 환율 기준 시각과 시세 수신·평가 시각은 구분한다. API 확인 후 출처·갱신·지연 여부 확인 방법을 정한다. |
| 거래 기록의 원화 금액 | 과거 주문·거래·실현손익을 당시 기록된 환율로 환산한 금액. 당시 환율을 확인하지 못하면 ‘확인 불가’로 표시한다. 최신 환율로 다시 환산하지 않는다. |
| 시간가중수익률(TWR) | 계산 범위에 들어오거나 나가는 자금 이동 시점마다 투자성과를 구간으로 나누고, 구간별 수익률을 복리로 연결하는 방식. AI별 운용 추이 그래프에 사용하며 보유 수익률과 구분한다. 개인↔AI 이동은 해당 AI에 자금 이동이며, 전체에는 내부 이동이다. |
| TWR 운용기간 | 해당 범위의 자금 운용 성과를 이어 계산하는 기간. 실제 자산이 0이 되면 종료한다. 다시 자금이 들어오면 새 기간을 시작한다. 이전 기간의 수익률·거래내역·누적 실현손익은 보존한다. 전액 회수 자체는 투자 손실로 계산하지 않는다. AI 중지·재개만으로 기간을 나누지 않는다. |
| 성과 평가 기록 | 특정 시점의 AI 자산 평가액·TWR·적용 환율과 기준 시각을 저장한 기록. 한국시간 매일 00:00과 해당 AI의 자금 이동 직전·직후에 남기며, 시장별 종가 기록 및 주문·체결·AI 판단 기록과 구분한다. |
| 현재 낙폭 | 현재까지 가장 높았던 누적 TWR 수준에서 현재 성과가 얼마나 하락했는지 나타내는 비율. |
| 최대 낙폭(MDD) | 한 운용기간의 저장된 성과 평가 기록에서 고점 이후 가장 크게 하락했던 비율. 초기에는 기록 사이의 장중 저점을 포함하지 않는다. |
| 금액가중수익률(MWR) | 자금을 얼마나, 언제 투입·회수했는지까지 반영하는 방식. 실제 투자자금의 성과를 평가하는 데 사용한다. |

TWR·MWR의 계산 개념은 [GIPS 공식 설명](https://www.gipsstandards.org/standards/gips-standards-for-firms/gips-standards-handbook-for-firms/)을 참고한다.

- AI TWR은 실제 거래 세금·수수료가 반영된 해당 AI의 현금과 보유종목의 현재가 평가금액을 원화로 합산해 계산한다.
- 예상 매도 비용은 순평가손익에 반영하며, TWR에서는 차감하지 않는다.
- API 확인 후 환율 출처와 갱신·지연 여부 확인 방법을 정한다.

예를 들어 평균매입가 10,000원인 주식의 전일 종가가 12,000원이고 현재가가 11,000원이면, **등락은 −1,000원**, **비용 반영 전 평가손익은 주당 +1,000원**이다.

## 투자 주체별 자금·장부

| 용어 | 뜻과 프로젝트 기준 |
|---|---|
| AI 트레이더 | 배정받은 자금과 설정된 투자대상 범위 안에서 종목과 매매 시점을 판단하고 매매를 진행하는 AI 운용 주체. 트레이더마다 자금·보유·거래·성과 장부와 실행·중지 상태를 독립적으로 관리한다. |
| 투자대상 모드 | 트레이더의 후보 탐색·매매 종목 범위. 생성 화면과 상세의 투자대상 수정에서 AI 선정 또는 직접 선택으로 정하고 트레이더별로 저장한다. |
| AI 선정 | 기본 투자대상 모드. AI가 매 판단마다 프로젝트 투자 범위 안에서 후보를 자율 탐색한다. 저장된 직접 선택 목록은 빈 상태다. |
| 직접 선택 | 사용자가 지정한 하나 이상의 종목 안에서 AI가 판단·매매하는 투자대상 모드. 종목 검색과 현재 관심종목에서 추가하며, 트레이더별 대상 목록은 개인 관심목록과 독립적으로 보존한다. |
| 투자 주체 | 앱에서 자금·보유·거래·성과가 귀속되는 단위. 개인 또는 특정 AI 트레이더다. |
| 실계좌·투자 주체별 장부 | 개인과 모든 AI 트레이더의 실제 거래는 토스 실계좌 하나에서 진행한다. 앱 장부에서 개인·각 트레이더의 자금·보유·거래·성과를 따로 관리한다. |
| 운용금액·최초 배정금 | 사용자가 AI 트레이더에게 처음 배정한 자금. 주문에는 거래 결과와 비용을 반영한 사용 가능 현금을 사용한다. 최초 배정금 기록은 유지한다. |
| 현금 잔액 | 해당 투자 주체의 앱 내부 장부상 현금 전체. 주문에 묶인 현금도 포함한다. |
| 사용 가능 현금 | 주문에 묶인 금액 등을 제외해 다른 주문·배정·회수에 쓸 수 있는 확인된 금액. |
| 주문에 묶인 현금 | 해당 투자 주체의 주문에 사용 중이라 중복 사용하지 못하는 금액. |
| 자금·수량 예약과 해제 | 해당 투자 주체의 주문에 필요한 현금·수량을 중복 사용하지 못하게 묶고, 종료 확인 후 남은 예약분을 같은 주체가 다시 사용할 수 있게 하는 것. |
| 추가 배정·회수 | 개인과 특정 AI 사이에서 사용 가능한 현금을 이동하는 것. 최초 배정금은 유지하고 별도로 기록하며, 투자수익·손실로 계산하지 않는다. |
| 재투자 | 해당 AI가 거래로 얻은 수익을 자신의 다음 투자에 사용하는 것. 최초 배정금 설정을 변경하지 않는다. |
| 장부 대조 | 개인·모든 AI의 현금·보유수량 합계를 실제 계좌와 비교하는 것. 자산이 중복 또는 누락되어 기록됐는지 확인한다. |
| 초단타·중기·장기 | 프로젝트의 투자 유형. 초단타는 수초~수분 매매와 당일 청산을 기본으로 한다. 중기는 수일~수주, 장기는 수개월 이상을 기본 기준으로 한다. |
| 투자 전략·관망 | 전략은 후보 선정과 매수·매도 판단의 기준이다. 관망은 현재 판단에서 주문을 제출하지 않고 상황을 지켜보는 선택이다. |

앱 장부의 현금 잔액·사용 가능 현금·주문에 묶인 현금과 증권사 계좌의 예수금·주문가능금액·출금가능금액은 각 정의에 따라 별도로 관리한다.
