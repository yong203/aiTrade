# 금융 용어

요구사항과 대화에서 사용하는 용어를 정리한다. 프로젝트의 확정·미정 사항은 [요구사항](REQUIREMENTS_AND_DESIGN.md)을 기준으로 한다.

## 상품·시세·시장

| 용어 | 뜻과 프로젝트 기준 |
|---|---|
| 주식 | 회사의 소유 지분을 나타내는 증권. [주식의 기본 개념](https://www.investor.gov/introduction-investing/investing-basics/investment-products/stocks) |
| ETF(상장지수펀드) | 거래소에 상장되어 주식처럼 매매하는 펀드. 지수·자산 등을 추종하는 상품 등이 있다. [한국거래소 설명](https://open.krx.co.kr/contents/OPN/01/01030100/OPN01030100.jsp) |
| 종목 | 검색·시세 조회·매매의 대상이 되는 개별 주식이나 ETF. |
| 종목코드·티커 | 종목을 식별하는 코드. 국내 종목코드와 미국 티커를 사용하며, 시장 정보도 함께 구분한다. |
| 시장 | 종목이 거래되는 시장. 프로젝트에서는 국내와 미국을 구분해 시세·장 상태·주문 지원을 확인한다. |
| 거래 통화 | 해당 종목의 거래 금액을 표시하는 통화. 국내는 원화(KRW), 미국은 달러(USD)를 사용한다. |
| 관심종목 | 사용자가 관찰하려고 등록한 종목. 실제 보유 여부와 독립적이다. |
| 보유종목·보유수량 | 실제 소유한 종목과 그 수량. 앱에서는 개인·각 AI별 귀속을 구분한다. |
| 현재가 | 최신 제공 가격. 실제 주문의 체결가격을 보장하는 값은 아니다. |
| 전일 종가 | 직전 거래일에 장이 끝날 때의 가격. 이 프로젝트의 등락 기준은 직전 거래일 **정규장** 종가다. |
| 등락 금액 | 현재가에서 등락 기준 가격을 뺀 금액. 매입가 대비 투자손익과 구분한다. |
| 등락률 | 등락 금액을 기준 가격으로 나눈 비율. 종목의 전일 대비 변화를 나타낸다. |
| 거래량 | 일정 기간에 거래된 수량. |
| 호가 | 매수·매도하려는 가격 제시. 호가창은 가격별 주문 수량 등을 보여주는 화면이다. |
| 캔들·일봉 | 일정 시간의 시가·고가·저가·종가를 묶어 표시한 가격 기록. 일봉은 하루 단위 기록이다. |
| OHLCV | 시가(Open)·고가(High)·저가(Low)·종가(Close)·거래량(Volume). AI의 초기 가격·거래량 입력에 사용한다. |
| 거래일 | 해당 시장에서 거래가 진행되는 날짜. 한국시간 자정과 일치한다고 가정하지 않는다. |
| 정규장·시간외·세션 | 정규장은 시장의 기본 거래시간, 시간외는 그 밖의 거래 구간, 세션은 구분된 거래 구간이다. 시세 제공과 주문 지원 여부는 각각 확인한다. |
| 휴장·거래시간 외 | 휴장은 시장이 열리지 않는 날, 거래시간 외는 현재 거래 세션이 진행되지 않는 상태. 정보 조회 실패와 구분한다. |

가격·시장 데이터 항목은 [토스 공식 API 명세](https://openapi.tossinvest.com/openapi-docs/latest/openapi.json)를 참고한다.

## 주문·체결

주문 유형의 기본 개념은 [Investor.gov 설명](https://www.investor.gov/introduction-investing/investing-basics/how-stock-markets-work/types-orders), 접수·체결 상태는 [토스 공식 API 명세](https://openapi.tossinvest.com/openapi-docs/latest/openapi.json)를 참고한다.

| 용어 | 뜻과 프로젝트 기준 |
|---|---|
| 매수·매도 | 매수는 종목을 사는 것, 매도는 보유분을 파는 것. |
| 주문 | 증권사에 매수·매도를 요청하는 것. 요청했다고 거래가 완료된 것은 아니다. |
| 지정가 주문 | 매수 시 지정한 가격 이하, 매도 시 지정한 가격 이상에서 체결되도록 요청하는 주문. 체결되지 않을 수 있다. 초기 수동매매 방식이다. |
| 시장가 주문 | 체결가격을 지정하지 않고 현재 가능한 가격으로 거래를 요청하는 주문. 초기 수동매매에서는 후속 범위다. |
| 주문가격·주문수량·주문금액 | 요청한 가격·수량과 그에 따른 금액. 실제 체결가격·수량·금액과 구분한다. |
| 접수 | 증권사가 주문을 받아들인 상태. 체결과 구분한다. |
| 접수 확인 중 | 응답 단절 등으로 접수 여부가 불명확한 상태. 조회로 확인하며 같은 주문을 자동 재제출하지 않는다. |
| 체결 | 주문이 실제 거래로 성립한 것. 보유·현금·거래내역은 실제 체결분에 따라 반영한다. |
| 미체결·부분체결 | 미체결은 아직 거래되지 않은 수량, 부분체결은 주문 수량 중 일부만 거래된 상태. |
| 평균 체결가격 | 한 주문이 여러 가격에 체결됐을 때, 체결금액을 체결수량으로 나눈 가격. 보유분의 평균매입가와 구분한다. |
| 정정·취소·거절 | 정정은 주문 조건 변경, 취소는 미체결 잔여분 철회, 거절은 요청이 받아들여지지 않은 것. 취소 요청 후 종료 여부를 확인한다. |
| 청산 | 보유분을 매도해 포지션을 종료하는 것. AI 중지는 미체결 자동 주문을 취소하며, 보유분을 자동 청산하는 동작은 아니다. |

## 매입원가·손익·비용

평균원가·선입선출의 기본 개념은 [Fidelity 설명](https://www.fidelity.com/tax-information/tax-topics/capital-gains-cost-basis)을 참고한다. 아래 비용 배분은 이 프로젝트의 투자 주체별 장부 기준이다.

| 용어 | 뜻과 프로젝트 기준 |
|---|---|
| 매입원가 | 보유분을 매수한 금액. 앱의 비용 반영 전 원가에는 세금·수수료를 포함하지 않고 별도 관리한다. |
| 평균매입가·이동평균 | 현재 보유분의 원가를 수량으로 나눈 주당 가격. 추가 매수 때 남은 보유분과 새 매수분으로 갱신한다. 개인·각 AI별로 계산하며, 차트의 주가 이동평균선과 구분한다. |
| 주가 이동평균선 | 일정 기간의 주가를 평균한 값을 이어 표시한 차트 지표. 보유분의 평균매입가와 다른 개념이며, 초기 전략에 사용할 지표로 확정한 것은 아니다. |
| 선입선출(FIFO) | 먼저 매수한 수량부터 매도된 것으로 원가를 계산하는 방식. 현재 앱 장부에는 채택하지 않았다. |
| 평가금액 | 현재 보유수량을 현재 가격으로 평가한 금액. 현금 잔액과 구분한다. |
| 실현손익 | 실제 매도 체결로 확정된 손익. 미체결 주문은 포함하지 않는다. |
| 평가손익 | 현재 보유분의 평가금액과 남은 매입원가에 따른 손익. 가격이 변하면 달라진다. |
| 총손익 | 같은 통화·비용 반영 기준의 누적 실현손익과 현재 보유분 평가손익을 합한 금액. |
| 비용 반영 전 손익 | 거래가격·원가 차이로 계산한 손익. 세금·수수료를 차감하기 전 금액이다. |
| 세금·수수료·비용 합계 | 거래 비용의 세금과 증권사 수수료를 각각 표시하며, 둘을 합해 비용 합계로 표시한다. API의 거래 세금과 별도 신고·납부 세금은 구분해야 한다. |
| 별도 신고·납부 세금 | 거래별 비용과 별도로 신고·납부하는 세금. 국외주식 양도소득세처럼 별도 신고가 필요한 세금도 있다. 앱에서 계산할 범위는 미정이다. [국세청 안내](https://www.nts.go.kr/nts/na/ntt/selectNttInfo.do?bbsId=1028&mi=2201&nttSn=1353905) |
| 순손익 | 해당 손익에 귀속된 세금·수수료를 반영한 금액. 모든 신고세금을 납부한 뒤의 금액을 의미하지 않는다. |
| 비용 배분 | 이미 발생한 매수 비용을 매도 수량 비율에 따라 실현손익과 남은 보유분의 평가손익으로 나누는 것. 배분 자체로 현금을 다시 차감하지 않는다. |
| 예상 매도 비용 | 현재가로 남은 보유분 전부를 매도한다고 가정한 세금·수수료. ‘예상’으로 표시하며, 현금에서 실제 차감하지 않는다. |
| 수익률 | 기준 금액 대비 투자성과의 비율. 전일 대비 등락률과 다르다. 개인·전체·개별 AI의 대표 수익률은 원화 기준 TWR을 사용하며, 달러 자산의 환율 변화도 반영한다. |
| 원화 환산 | 달러 표시 금액에 적용 환율(1달러당 원화 금액)을 곱해 원화 평가액을 구하는 것. 대표 자산·TWR 계산에 사용하며 실제 환전은 아니다. 적용 환율과 기준 시각을 기록하고, 종목 가격·거래금액은 원래 통화로 표시한다. |
| 시간가중수익률(TWR) | 계산 범위에 들어오거나 나가는 자금 이동 시점마다 투자성과를 구간으로 나누고, 구간별 수익률을 복리로 연결하는 방식. 개인·전체·개별 AI의 대표 수익률에 적용한다. 개인↔AI 이동은 개인·해당 AI에는 자금 이동이지만, 전체에는 내부 이동이다. |
| TWR 운용기간 | 해당 범위의 자금 운용 성과를 이어 계산하는 기간. 실제 자산이 0이 되면 종료하고, 다시 자금이 들어오면 새 기간을 시작한다. 이전 기간의 수익률·거래내역·누적 실현손익은 보존하며, 전액 회수 자체는 투자 손실로 계산하지 않는다. AI 중지·재개만으로 기간을 나누지 않는다. |
| 성과 평가 기록 | 특정 시점의 자산 평가액·TWR·적용 환율과 기준 시각을 저장한 기록. 한국시간 매일 00:00과 해당 계산 범위의 자금 이동 직전·직후에 남긴다. 일일 평가는 개인·전체·모든 AI에 같은 기준 시각을 적용하며, 시장별 종가 기록 및 주문·체결·AI 판단 기록과 구분한다. |
| 현재 낙폭 | 현재까지 가장 높았던 누적 TWR 수준에서 현재 성과가 얼마나 하락했는지 나타내는 비율. |
| 최대 낙폭(MDD) | 한 운용기간의 저장된 성과 평가 기록에서 고점 이후 가장 크게 하락했던 비율. 초기에는 기록 사이의 장중 저점을 포함하지 않는다. |
| 금액가중수익률(MWR) | 자금을 얼마나, 언제 투입·회수했는지까지 반영하는 방식. 실제 투자자금의 성과를 평가하는 데 사용한다. |

TWR·MWR의 계산 개념은 [GIPS 공식 설명](https://www.gipsstandards.org/standards/gips-standards-for-firms/gips-standards-handbook-for-firms/)을 참고한다. TWR은 실제 거래 세금·수수료가 반영된 해당 범위의 현금과 보유종목의 현재가 평가금액을 원화로 합산해 계산한다. 전체 TWR은 전체 자산으로 직접 계산하며, 개인·AI 수익률을 더하거나 단순 평균하지 않는다. 예상 매도 비용은 TWR에서 차감하지 않고 순평가손익에 반영한다. 환율 출처와 갱신·지연 여부 확인 방법은 API 확인 후 정한다.

예를 들어 평균매입가 10,000원인 주식의 전일 종가가 12,000원이고 현재가가 11,000원이면, **등락은 −1,000원**이지만 **비용 반영 전 평가손익은 주당 +1,000원**이다.

## 투자자별 자금·장부

| 용어 | 뜻과 프로젝트 기준 |
|---|---|
| 투자 주체 | 앱에서 자금·보유·거래·성과가 귀속되는 단위. 개인 또는 특정 AI 투자자다. |
| 실계좌·투자자별 장부 | 실제 거래는 토스 실계좌 하나에서 진행한다. 앱 장부가 개인·각 AI의 몫을 구분하며, AI별 별도 실계좌를 뜻하지 않는다. |
| 운용금액·최초 배정금 | 사용자가 AI에게 처음 배정한 자금. 고정 매입금액 상한이 아니며, 거래 결과와 비용에 따라 현재 자산은 달라진다. |
| 현금·사용 가능한 현금 | 현금은 해당 주체의 현금 잔액, 사용 가능한 현금은 주문에 묶인 금액 등을 제외한 확인된 금액이다. 앱의 사용 가능 현금과 증권사의 출금 가능 금액은 구분한다. |
| 자금·수량 예약과 해제 | 주문에 필요한 현금·수량을 중복 사용하지 못하게 묶고, 종료 확인 후 남은 예약분을 다시 사용할 수 있게 하는 것. 다른 투자자에게 이동시키는 동작은 아니다. |
| 추가 배정·회수 | 개인과 특정 AI 사이에서 사용 가능한 현금을 이동하는 것. 최초 배정금은 유지하고 별도로 기록하며, 투자수익·손실로 계산하지 않는다. |
| 재투자 | 해당 AI가 거래로 얻은 수익을 자신의 다음 투자에 사용하는 것. 최초 배정금 설정을 변경하지 않는다. |
| 장부 대조 | 개인·모든 AI의 현금·보유수량 합계를 실제 계좌와 비교하는 것. 자산이 중복 또는 누락되어 기록됐는지 확인한다. |
| 초단타·중기·장기 | 프로젝트의 투자 유형. 초단타는 수초~수분 매매와 당일 청산, 중기는 수일~수주, 장기는 수개월 이상을 기본 기준으로 한다. |
| 투자 전략·관망 | 전략은 후보 선정과 매수·매도 판단의 기준이다. 관망은 현재 판단에서 주문을 제출하지 않고 상황을 지켜보는 선택이다. |
